## 第一题：平衡括号字符串的最少插入次数 https://leetcode.cn/problems/minimum-insertions-to-balance-a-parentheses-string/description/?envType=daily-question&envId=2026-10-09

**思路：思维。这题单纯用栈模拟的话比较麻烦，所以可以直接用两个变量进行计数计算。如果遇到'('，说明此时需要2个')'进行匹配，并且要把前面没匹配完的给清除了；如果遇到')'，说明需要1个'('进行匹配，并且此时匹配的'('不够时再进行添加。最终遍历一遍，答案就是ans + need**

**Python代码：**
```python
class Solution:
    def minInsertions(self, s: str) -> int:
        ans = 0
        need = 0
        for ch in s:
            if ch == '(':
                need += 2
                if need % 2 == 1:
                    ans += 1
                    need -= 1
            else:
                need -= 1
                if need < 0:
                    ans += 1
                    need = 1
        return ans + need
```
