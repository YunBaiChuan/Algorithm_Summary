## 第一题：统计封闭岛屿的数目 https://leetcode.cn/problems/number-of-closed-islands/description/?envType=daily-question&envId=2026-10-25

**思路：思维 + dfs。首先从上下左右四个边缘出发，把遇到的0都dfs标记为1，接着开始整体遍历，中间遇到0就进行答案收集和dfs，最终得到答案**

**Python代码：**
```python
class Solution:
    def closedIsland(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0]) 
        
        def dfs(i: int, j: int):
            if i < 0 or j < 0 or i >= m or j >= n or grid[i][j] != 0:
                return
            grid[i][j] = 1
            dfs(i - 1, j)
            dfs(i + 1, j)
            dfs(i, j - 1)
            dfs(i, j + 1)
        
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 0 and (i == 0 or j == 0 or \
                i == m - 1 or j == n - 1):
                    dfs(i, j)
        
        ans = 0
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 0:
                    dfs(i, j)
                    ans += 1
        return ans           
```
