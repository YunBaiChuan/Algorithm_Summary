## 第一题：最小差值平方和 https://leetcode.cn/problems/minimum-sum-of-squared-difference/description/?envType=daily-question&envId=2026-10-10

**思路：思维 + 贪心。首先我们要知道，题目需要优化的目标是差值平方和，并且操作表明可以对相应数进行+-1操作，最终使得操作后的差值平方和最小。这个优化目标是一个凸函数，所以说是可以优化的。因此我们先算出差值，合并k1，k2到k。因为得到差值之后，无论是操作哪个数组，我们的大结果其实都是将差值-1。接着从大到小排序差值，进行贪心操作（使其差值尽量平均）。最终将剩余答案与修改后的答案相加，然后输出即可。**

**Python代码：**
```python
class Solution:
    def minSumSquareDiff(self, a: List[int], nums2: List[int], k1: int, k2: int) -> int:
        ans, k = 0, k1 + k2
        for i in range(len(a)):
            a[i] = abs(a[i] - nums2[i])
            ans += a[i] * a[i]
        if sum(a) <= k:
            return 0

        a.sort(reverse=True)
        a.append(0)
        for i, v in enumerate(a):
            ans -= v * v
            j = i + 1
            c = j * (v - a[j])
            if c < k:
                k -= c
                continue
            v -= k // j
            return ans + k % j * (v - 1) * (v - 1) + (j - k % j) * v * v
```
