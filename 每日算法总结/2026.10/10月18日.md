## 第一题：余数求和 https://www.nowcoder.com/practice/5d18ffe2c6cd45ac8d8040be19c96f14?channelPut=tracker2

**思路：分块。注意到本题数据量比较大，并且对于每段连续区间来说，其商值q相同（具有单调性），考虑分块。首先余数公式为$k\ mod\ i = k - (k // i)\ *\ i$，然后本题就是余数求和，那么套一层累积求和得到$\sum{k\ mod\ i} = n * k - q * \sum_{i = l} ^ {r} {i}$，这里$q = k // i$，在每段连续区间来说值不变，最终得到结果**

**Python代码：**

def solve():
    n, k = MII()
    ans = n * k
    l = 1
    while l <= n:
        if k // l == 0:
            break
        q = k // l
        r = fmin(n, k // q)
        ans -= q * (l + r) * (r - l + 1) // 2
        l = r + 1
    print(ans)
