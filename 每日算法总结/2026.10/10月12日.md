## 第一题：对数组执行操作使平方和最大 https://leetcode.cn/problems/apply-operations-on-array-to-maximize-sum-of-squares/description/?envType=daily-question&envId=2026-10-12

**思路：思维。首先要观察到00和11这两种交换情况，其实对于&和|的更新来说没有帮助，因此主要还是01和10这两种情况；对于01和10这两种情况来说，本质上就是交换对应数位的1和0，并且我们可以知道要让数的平方和尽可能大，那么就要让1尽可能聚集；那么就先统计所有数的数位1个数，接着构造出k个数，并且是从高数位开始构造，然后将构造出来的数平方后加入答案中，最后取mod即可**

**Python代码：**
```python
class Solution:
    def maxSum(self, nums: List[int], k: int) -> int:
        m = max(nums).bit_length()
        cnt = [0] * m
        for x in nums:
            for i in range(m):
                cnt[i] += x >> i & 1
        ans = 0
        for _ in range(k):
            x = 0
            for i in range(m):
                if cnt[i]:
                    cnt[i] -= 1
                    x |= 1 << i
            ans += x * x
        return ans % (10 ** 9 + 7)
```
