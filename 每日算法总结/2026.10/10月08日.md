## 第一题：删除最外层的括号 https://leetcode.cn/problems/remove-outermost-parentheses/description/?envType=daily-question&envId=2026-10-08

**思路：思维。观察到就是删除深度为0的外层括号，深度>0的括号进行保留。因此遍历一遍，更新深度之后进行答案的收集即可**

**Python代码：**
```python
class Solution:
    def removeOuterParentheses(self, s: str) -> str:
        d = -1
        ans = ""
        for x in s:
            if x == '(':
                d += 1
                if d >= 1:
                    ans += x 
            else:
                d -= 1
                if d >= 0:
                    ans += x
        return ans
```

**思路：思维 + 组合数学。根据题意可知，我们的操作相当于是从1-n中间，也就是n-2个点中，选出m - 1次操作的方案数，所以说答案就是comb(n - 2, m - 1)**
