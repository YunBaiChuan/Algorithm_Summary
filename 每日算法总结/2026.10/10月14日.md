## 第一题：小红的因式分解 https://www.nowcoder.com/practice/b4b3c3c193ad43e5bc66018b1141cdb3?channelPut=tracker2

**思路：数学。题意很简单，就是怎么把二次方程分解成两个多项式。如果考虑常用的十字交叉相乘法，那就需要分解出a因子对，c因子对，然后两边的因子对进行枚举匹配，算对应b是否满足条件。但是有个很大的问题在于负数，本题是可能出现负数的，因此这个方法不仅麻烦，而且时间复杂度不行。那就直接暴力求根公式算出两个根，然后再用式子进行进一步验证，即分解为a(x - r1) \* (x - r2)，然后判断是否都是整数**

**Python代码：**
```python
import sys
input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''
a1a2x^2 + (a1b2 + a2b1)x + b1b2
a = a1a2
b = a1b2 + a2b1
c = b1b2
'''

def solve():
    a, b, c = LII()

    if a == 0:
        return "%d %d %d %d" % (b, c, 0, 1)

    delta = b * b - 4 * a * c
    if delta < 0:
        return "NO"

    zr = isqrt(delta)
    if zr * zr != delta:
        return "NO"

    g1 = math.gcd(abs(-b + zr), abs(2 * a))
    g2 = math.gcd(abs(-b - zr), abs(2 * a))

    l1 = abs(2 * a) // g1
    l2 = abs(2 * a) // g2

    if abs(a) % (l1 * l2) != 0:
        return "NO"

    x1 = (-b + zr) * l1 // (2 * a)
    x2 = (-b - zr) * l2 // (2 * a)

    l3 = a // (l1 * l2)

    return "%d %d %d %d" % (l1 * l3, -x1 * l3, l2, -x2)

# t = 1
t = II()
for _ in range(t):
    print(solve())
```
