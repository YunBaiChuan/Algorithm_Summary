## 第一题：有效的括号 https://leetcode.cn/problems/valid-parentheses/description/?envType=daily-question&envId=2026-10-01

**思路：栈模拟。括号匹配经典解决方法——栈模拟，直接模拟一遍即可**

**Python代码：**
```python
class Solution:
    def isValid(self, s: str) -> bool:
        st = []
        for x in s:
            if x in '([{':
                st.append(x)
            else: 
                if not st or x == ')' and st[-1] != '(' or x == ']' and st[-1] != '[' or x == '}' and st[-1] != '{':
                    return False 
                st.pop()
        return True if not st else False
```
