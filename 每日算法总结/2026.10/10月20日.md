**思路：思维 + 质因数分解。根据题意，其实就是算质因数分解之后的累加和。因此做一个质因数分解，并每次将分解后的数加入到答案即可。同时要注意ans初始化为n，最后判断一下n是否>1，来得到ans在质因数分解阶段是否+1过了。最终，输出答案即可**

**Python代码：**
```python

def solve():
    n = II()
    ans = n
    for i in range(2, isqrt(n) + 1):
        while n % i == 0:
            n //= i
            ans += n
    if n > 1: ans += 1
```
