## 第一题：括号的分数 https://leetcode.cn/problems/score-of-parentheses/description/?envType=daily-question&envId=2026-10-05

**思路：思维。注意到括号分数和最内部括号的嵌套深度存在联系，其公式可以表示为$2^d$。因此，我们只需要遍历一遍，然后算每个最内部嵌套括号的深度，并且得到其分数，然后累加即可**

**Python代码：**
```python
class Solution:
    def scoreOfParentheses(self, s: str) -> int:
        ans = depth = 0 
        for i, ch in enumerate(s):
            if ch == '(':
                depth += 1
            else:
                depth -= 1 
                if s[i - 1] == '(':
                    ans += 1 << depth 
        return ans 
```

**思路：思维。主要是要知道一个数学结论：对于4的倍数来说，只需要末尾两位是4的倍数即可。因此，我们只需要遍历一遍末尾两位数，判断其是否为4的倍数，然后输出答案即可。这里有个技巧就是把末两位拼接到开头，可以让逻辑统一起来，并且上述结论需要在两位数及以上才能用，所以说单位数就要写个特判**
