## 第一题：数位和排序需要的最小交换次数 https://leetcode.cn/problems/minimum-swaps-to-sort-by-digit-sum/description/?envType=daily-question&envId=2026-10-17

**思路；思维 + 并查集。首先根据题意，把数组先排好序，接着就是如何处理最小交换次数了。这里其实有个经典结论：最小交换次数为n - 置换环的个数，也就是n - 连通块的数目（这个结论其实是用一个置换环长度 - 1，推广到多个置换环长度 - c，其实就是n - c得到的）。因此再用一个并查集算出置换的连通块数目，再用n减去它，得到答案**

**Python代码：**
```python
class UnionFind:
    def __init__(self, n: int):
        self._fa = list(range(n))
        self.cc = n

    def find(self, x: int) -> int:
        if self._fa[x] != x:
            self._fa[x] = self.find(self._fa[x])
        return self._fa[x]

    def merge(self, from_: int, to: int) -> None:
        x, y = self.find(from_), self.find(to)
        if x == y:
            return
        self._fa[x] = y
        self.cc -= 1

class Solution:
    def minSwaps(self, nums: List[int]) -> int:
        a = sorted((sum(map(int, str(x))), x, i) for i, x in enumerate(nums))
        n = len(a)
        u = UnionFind(n)
        for i, t in enumerate(a):
            u.merge(i, t[2])
        return n - u.cc
```

## 第二题：加减 https://www.nowcoder.com/practice/b6aff86eef4f4622aec75154fbf183c7?channelPut=tracker2

**思路：思维 + 中位数 + 前缀和 + 双指针。本题是在有变化次数限制的情况下，算有多少元素能够变成相同元素。先考虑一个简单的问题，如果没有变化次数限制，要让所有元素变成相同元素，该选哪个元素？答案应该是中位数，这是个经典结论。那对于本题来说，我们其实可以采用局部的中位数来进行计算，再通过前缀和以及双指针枚举区间来计算限制次数 <= k的情况下，最大相同元素个数/区间长度**

**Python代码：**
```python

def solve():
    n, k = MII()
    a = LII()

    a.sort()
    P = [0] * (n + 1)
    for i in range(n):
        P[i + 1] = P[i] + a[i]

    ans = 1
    l = 0
    for r in range(n):
        while l <= r:
            med = (l + r) // 2
            m = a[med]
            left_cost = m * (med - l) - (P[med] - P[l])
            right_cost = (P[r + 1] - P[med + 1]) - m * (r - med)
            cost = left_cost + right_cost
            if cost > k:
                l += 1
            else:
                break
        ans = fmax(ans, r - l + 1)
    print(ans)
```
