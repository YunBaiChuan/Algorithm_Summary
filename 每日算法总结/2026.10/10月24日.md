## 第一题：一刀二分三角形 https://www.nowcoder.com/practice/a6476efb602c4e52935825b0d4c4c8ea?channelPut=tracker2

**思路：思维 + 二分 + 数学。首先二分是比较容易想到的，然后check函数里面要用到相似三角形。这里相似指的是划分出来的小直角三角形和(xc, 0)为顶角的大直角三角形相似，而不是整个大三角形。还有一个很重要的点在于xc与二分x0的位置关系，这会影响到左侧划分出来的形状，导致面积计算不同，这个容易漏想。然后就是这题不输出具体值，而是输出能否划分，那就带进去验证一遍，得到答案即可**

def solve():
    xb, xc, yc = LII()
    s = xb * yc

    def left2(x0):
        if x0 <= xc:
            return (x0 * x0 * yc, xc)
        else:
            return (s * (xb - xc) - (xb - x0) * (xb - x0) * yc, xb - xc)

    def check(mid):
        num, den = left2(mid)
        return 2 * num >= s * den

    l, r = 0, xb
    while l <= r:
        mid = (l + r) >> 1
        if check(mid):
            r = mid - 1
        else:
            l = mid + 1

    if l <= xb:
        num, den = left2(l)
        if 2 * num == s * den:
            print("YES")
            return
    print("NO")

# t = 1
t = II()
for _ in range(t):
    solve()
