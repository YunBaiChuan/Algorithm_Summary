## 第一题：将一个字符串排序的最小操作次数 https://leetcode.cn/problems/minimum-operations-to-sort-a-string/description/?envType=daily-question&envId=2026-10-21

**思路：分类讨论。首先题目要求不能选择整个字符串，因此最好是选除开第一个以外/最后一个以外的其他所有元素作为子串；接着就可以讨论不同情况下的操作次数了：1.已经是非降序情况下为0；2.不满足1且长度为2情况下为-1无法完成；3.最小/最大值在开头/结尾情况下为1；4.最大/最小值在中间情况下为2；5.如果都不行，那就是3次**

**Python代码：**
```python
class Solution:
    def minOperations(self, s: str) -> int:
        if all(x <= y for x, y in pairwise(s)):
            return 0 
        
        if len(s) == 2:
            return -1 
        
        mn = min(s)
        mx = max(s)

        if s[0] == mn or s[-1] == mx:
            return 1
        
        if any(ch == mn or ch == mx for ch in s[1:-1]):
            return 2 
        
        return 3
```
