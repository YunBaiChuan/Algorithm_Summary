**思路：思维 + 贪心 + 分类讨论。首先我们要求出目前数组和s与目标数组和target相差多少，得到need之后就可以进行分类讨论了：1.need = 0时满足条件，直接输出即可；2.need > 0时，我们需要增加数值，那么就可以贪心地把a从小到大排序，从小的增加，它就可以增加更多，需要增加的元素就会更少；3.need < 0时则与情况2同理，只不过是反过来的。最后，情况2和情况3分别遍历一遍a，算出答案并输出即可**

**Python代码：**
```python
import sys
input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''

'''

def solve():
    n, target = MII()
    a = LII()
    s = sum(a)
    need = target - s

    if need == 0:
        print(0)
        return

    if need > 0:
        a.sort()
        ans = 0
        for x in a:
            need -= fmin(need, 10 ** 4 - x)
            ans += 1
            if need <= 0:
                print(ans)
                return
    else:
        a.sort(reverse=True)
        ans = 0
        for x in a:
            need += fmin(-need, 10 ** 4 + x)
            ans += 1
            if need >= 0:
                print(ans)
                return

# t = 1
t = II()
for _ in range(t):
    solve()
```
