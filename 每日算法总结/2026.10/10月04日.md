## 第一题：有效的括号字符串 https://leetcode.cn/problems/valid-parenthesis-string/description/?envType=daily-question&envId=2026-10-04

**思路：思维。先把\*当作(，然后从左往右匹配一遍，看是否满足条件；接着再把\*当作)，然后从右往左匹配一遍，看是否满足条件。综合这两种情况得到答案**

**Python代码：**
```python
class Solution:
    def checkValidString(self, s: str) -> bool:
        cnt = 0
        for ch in s:
            if ch == '(' or ch == '*':
                cnt += 1
            else:
                cnt -= 1
            if cnt < 0:
                return False
        
        cnt = 0
        for ch in reversed(s):
            if ch == ')' or ch == '*':
                cnt += 1
            else:
                cnt -= 1
            if cnt < 0:
                return False
        
        return True
```

## 第二题：小绿的房子 https://www.nowcoder.com/practice/dfab1015071f4d37b4f6e174b447c7c0?channelPut=tracker2

**思路：思维 + 树的直径。两次bfs找树上的直径端点，然后判断每个点到这两个端点的距离是否满足条件即可**

def solve():

    g = [[] for _ in range(n + 1)]
    for _ in range(n - 1):

    def bfs(s):
