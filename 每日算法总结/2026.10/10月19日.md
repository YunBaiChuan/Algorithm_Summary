**思路：思维 + 栈 + 双指针。这题主要是两种删除情况该如何抉择？答案是先用栈邻项相消，然后用双指针首尾相消，这种方式最简单，并且能保证留下的元素最少，也就是删除的元素最多。两个顺序反一下也是可以的，不过会更麻烦一点**

**Python代码；**

def solve():
    n = II()
    s = I()

    st = []
    for x in s:
        if st and st[-1] == x:
            st.pop()
        else:

    l, r = 0, len(st) - 1

        l += 1
        r -= 1

    print(n - (r - l + 1 if l <= r else 0))
