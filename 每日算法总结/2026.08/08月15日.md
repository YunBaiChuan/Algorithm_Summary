## 第一题：按位异或非零的最长子序列 https://leetcode.cn/problems/longest-subsequence-with-non-zero-bitwise-xor/description/?envType=daily-question&envId=2026-08-15

**思路：思维。首先考虑一个特判，当元素都是0的时候，结果必然为0；然后对于其他情况来说，我们先把所有元素异或起来得到异或和，如果异或和非零那么答案就是n，否则我们可以根据异或的性质来去掉某个元素，就可以得到非零结果，直接输出n - 1即可**

**代码：**
```cpp
class Solution {
public:
    int longestSubsequence(vector<int>& nums) {
        int n = nums.size();
        int res = 0;
        bool flag = false;
        for (int i = 0; i < n; i++) {
            if (nums[i] != 0) flag = true;
            res ^= nums[i];
        }
        if (!flag) return 0;
        return res == 0 ? n - 1 : n;
    }
};
```
