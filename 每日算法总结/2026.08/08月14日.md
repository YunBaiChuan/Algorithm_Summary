## 第一题：猫猫与数列 https://www.nowcoder.com/practice/92229fa334d24d71b9cfd9c81fb77c39?channelPut=tracker2

**思路：模拟。根据题意模拟即可，但是cpp的溢出就挺恶心的处理起来。比较常见的方法就是乘法变除法，也就是前面用到过的技巧$a * b < limit$变成$a < limit / b$**

**代码：**
```cpp
#include <iostream>
using namespace std;

using ll = long long;
const ll inf = 1e18;

void solve() {
    ll p, q;
    cin >> p >> q;
    int n = 2;
    while (true) {
        ll r = p;
        for (int i = 1; i < q; i++) {
            if (r > inf / p) {
                cout << n << '\n';
                return;
            }
            r *= p;
        }
        p = q;
        q = r;
        n++;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```
