**思路：思维 + dfs。由题意可知，我们都是黑白交替的链，因此要使得最终链最长，即为1的话，就需要链两端都为黑色，或者单独一个黑色。因此，我们只需要统计黑色端点的个数，也就是当根节点深度为0时，所有偶数深度的节点个数。就可以通过两个部分算答案了：1.cnt本身；2.cnt * (cnt - 1) // 2，也就是以两个黑色为两个端点形成的链**

**代码：**

import sys

import math

    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LII():

def solve():
    n = II()
    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        u, v = MII()
        u -= 1; v -= 1
        g[u].append(v)
        g[v].append(u)

    dep = [0] * n
    stack = [(0, -1)]
    while stack:
        u, p = stack.pop()
        for v in g[u]:
            if v != p:
                dep[v] = dep[u] + 1
                stack.append((v, u))

    cnt = sum(1 for d in dep if d % 2 == 0)
    print(cnt * (cnt + 1) // 2) # 单独cnt匹配 + 从cnt里面选两个C(cnt, 2)匹配

# t = 1
t = II()
for _ in range(t):
    solve()
