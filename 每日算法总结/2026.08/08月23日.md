## 第一题：求和游戏 https://leetcode.cn/problems/sum-game/description/?envType=daily-question&envId=2026-08-23

**思路：思维 + 博弈论。分析题目可以得到结论：对于?来说，我们将其视作数字9；对于数字来说，我们将其\*2。然后前半部分用加法，后半部分用减法，最终判断下累加结果是否为0**

**Python代码：**
```python
class Solution:
    def sumGame(self, num: str) -> bool:
        m = len(num) // 2 
        d = 0 
        for i, ch in enumerate(num):
            x = int(ch) * 2 if ch != '?' else 9 
            d += x if i < m else -x 
        return d != 0
```

**Cpp代码：**
```cpp
class Solution {
public:
    bool sumGame(string num) {
        int m = num.size() / 2;
        int d = 0;
        for (int i = 0; i < num.size(); i++) {
            int x = num[i] == '?' ? 9 : (num[i] - '0') * 2;
            d += i < m ? x : -x;
        }
        return d != 0;
    }
};
```
