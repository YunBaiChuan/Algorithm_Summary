## 第一题：将元素分配到两个数组中 I https://leetcode.cn/problems/distribute-elements-into-two-arrays-i/description/?envType=daily-question&envId=2026-08-20

**思路：模拟。纯纯模拟题，没什么太多好说的**

**代码1：Python**
```python
class Solution:
    def resultArray(self, nums: List[int]) -> List[int]:
        res1, res2 = [nums[0]], [nums[1]]
        for i in range(2, len(nums)):
            if res1[-1] > res2[-1]:
                res1.append(nums[i])
            else:
                res2.append(nums[i])
        return res1 + res2
```

**代码2：Cpp**
```cpp
class Solution {
public:
    vector<int> resultArray(vector<int>& nums) {
        vector<int> res1{nums[0]}; // vector有点类似于list列表，这里初始化需要学习下
        vector<int> res2{nums[1]};
        
        for (int i = 2; i < nums.size(); i++) {
            // 用.back()可以直接访问vector的最后一个元素，比用索引更方便
            if (res1.back() > res2.back()) {
                res1.emplace_back(nums[i]);
            } else {
                res2.emplace_back(nums[i]);
            }
        }

        // cpp没有vector拼接，因此可以用.insert()插入来写，就是被插入的起始位置，要插入的起始位置与结束位置
        res1.insert(res1.end(), res2.begin(), res2.end());
        return res1;
    }
};
```

## 第二题：好串 https://www.nowcoder.com/practice/18363d6c6ae34f1cb85634617f897756?channelPut=tracker2

**思路：思维 + 分类讨论。首先我们可以遍历一遍，找相邻不同的个数，其实就是"01"或者"10"子串的个数，这个比较好想；然后就是分类讨论了，如果cnt >= 3那么直接输出0即可，已经满足条件了；如果cnt == 0，说明整个串相同，只需要2次操作就能满足条件；如果此时s为"1001"，"0110"，"1100"，"0011"中的一个，那么也是需要2次操作才行；然后剩下的情况只需要1次操作即可**

```cpp
#include <iostream>
#include <vector>
using namespace std;

using ll = long long;
const ll inf = 1e18;

void solve() {
    int n;
    cin >> n;
    string s;
    cin >> s;

    int cnt = 0;
    for (int i = 1; i < n; i++) {
        cnt += (s[i] != s[i - 1]);
    }
    if (cnt >= 3) {
        cout << 0 << '\n';
    } else if (cnt == 0 || s == "1001" || s == "0110" || s == "1100" || s == "0011") {
        cout << 2 << '\n';
    } else {
        cout << 1 << '\n';
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T = 1;
    cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```
