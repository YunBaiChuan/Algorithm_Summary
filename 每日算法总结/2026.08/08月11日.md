## 第一题：大于等于顺序前缀和的最小缺失整数 https://leetcode.cn/problems/smallest-missing-integer-greater-than-sequential-prefix-sum/description/?envType=daily-question&envId=2026-08-11

**思路：模拟。题目翻译拉了，没明确说是从0索引开始的前缀最长连续子数组。主要是学习语法吧这题，有几个语法需要注意：1.vector转set，set里面的参数是nums.begin(), nums.end()；2.vector求长度用.size()，和pytorch里面求维度类似；3.求vector最大值/最小值用max_element，不过返回结果是迭代器，需要用*解引用一下；4.cpp函数末尾必须要有明确返回值，这点和python不同**

**代码：**
```cpp
class Solution {
public:
    int missingInteger(vector<int>& nums) {
        set<int> st(nums.begin(), nums.end());
        int l = 1, s = nums[0];
        for (int i = 1; i < nums.size(); i++) {
            if (nums[i] == nums[i - 1] + 1) {
                s += nums[i];
                l++;
            } else {
                break;
            }
        }

        int maxVal = *max_element(nums.begin(), nums.end());
        for (int i = s; i <= maxVal + 1; i++) {
            if (!st.count(i)) {
                return i;
            }
        }
        return s;
    }
};
```

## 第二题：简单题的逆袭 https://www.nowcoder.com/practice/579b734002034f38a3af95e7843ae400?channelPut=tracker2

**思路：思维。就不断从x开始乘就行，不过对于cpp来说，要考虑溢出问题，所以说就可以把式子$power * x <= y$改写成$power <= y / x$来避免溢出。然后考虑一下特判，对于x = 0或1的情况来说都是无法满足的，还有y = 0的情况也不行。这里附上一个快速幂qpow写法，需要掌握**

**代码：**
```cpp
#include <iostream>
#include <cmath>
using namespace std;

using ll = long long;
const ll inf = 1e18;

ll qpow(ll x, ll k) {
    ll res = 1;
    while (k) {
        if (k & 1) res *= x;
        x *= x;
        k >>= 1;
    }
    return res;
}

void solve() {
    ll x, y;
    cin >> x >> y;
    if (x == 0 || x == 1 || y == 0) {
        cout << -1 << '\n';
        return;
    }

    ll k = 0;
    ll power = 1;
    while (power <= y / x) { // 防溢出
        power *= x;
        k++;
    }
    cout << k << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```
