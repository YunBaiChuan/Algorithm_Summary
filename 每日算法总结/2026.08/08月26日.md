## 第一题：最短且字典序最小的美丽子字符串 https://leetcode.cn/problems/shortest-and-lexicographically-smallest-beautiful-string/description/?envType=daily-question&envId=2026-08-26

**思路：不定长滑动窗口。这题虽然说是恰好，但它不是恰好滑动窗口类型，就是一个普通的不定长滑动窗口，并且要求字典序尽可能小的话，需要满足一个大前提和两个小前提之一，也就是首先子串中的'1'数量要恰好为k，然后任意满足长度更小/长度相同但字典序更小这两种情况之一。最终，输出答案即可**

**Python代码：**
```python
class Solution:
    def shortestBeautifulSubstring(self, s: str, k: int) -> str:
        ans = '1' * 101
        cnt = l = 0
        for r, x in enumerate(s):
            cnt += int(x)
            while cnt > k:
                cnt -= int(s[l])
                l += 1
            while cnt == k and s[l] == '0':
                l += 1
            if cnt == k and (len(s[l: r + 1]) < len(ans) or (len(s[l: r + 1]) == len(ans) and s[l: r + 1] < ans)):
                ans = s[l: r + 1]
        return ans if ans < '1' * 101 else ''
```

**Cpp代码：Cpp代码细节挺多的，首先是string初始化，不能用Python的\*号；然后也不能用int转化和切片，并且注意Cpp的substr切片方式与Python不同，它的参数为起始索引及长度，而不是起始索引和结束索引；最后要注意的是，返回空字符串类型必须用""，单引号''是不对的，那是空字符而非空字符串**
```cpp
class Solution {
public:
    string shortestBeautifulSubstring(string s, int k) {
        string mx(101, '1');
        string ans = mx;
        int cnt = 0, l = 0;
        for (int r = 0; r < s.size(); r++) {
            cnt += (s[r] - '0');
            while (cnt > k) {
                cnt -= (s[l] - '0');
                l++;
            }
            while (cnt == k && s[l] == '0') {
                l++;
            }
            string t = s.substr(l, r - l + 1);
            if (cnt == k && (t.size() < ans.size() || (t.size() == ans.size() && t < ans))) {
                ans = t;
            }
        }
        return ans < mx ? ans : "";
    }
};
```

## 第二题：强迫症 https://www.nowcoder.com/practice/a6961375c2ce4957a4335dff6b13a4b1?channelPut=tracker2

**思路：思维 + 贪心。这题目的操作翻译过来其实就是对于每个数，我可以把其他某个数加到自己身上，变成一个新的数，并且这个数不能和其他数重复。有个思路就是，每个重复的数都与当前的最大值进行相加，举个例子：1 1 1 2 2 2，那么第一次操作后就是 3 1 1 2 2 2，第二次为 3 4 1 2 2 2，第三次 3 4 1 6 2 2，第四次 3 4 1 6 8 2，这样就不会重复了。因此操作次数其实就是n - len(set(a))**

**Cpp代码：还是那个说法，用无序的map才是hash表，效率会更高点，类似于Python的字典。然后它的遍历就是用auto&，这样不会额外复制一遍，并且写一大串数据类型，然后用first、second进行调用**
```cpp
#include <iostream>
#include <unordered_map>
using namespace std;

using ll = long long;
const ll inf = 1e18;

void solve() {
    int n;
    cin >> n;
    unordered_map<int, int> d;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        d[x]++;
    }
    int ans = 0;
    for (auto& p: d) {
        ans += p.second - 1;
    }
    cout << ans << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cout.tie(nullptr);

    int T = 1;
    // cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```
