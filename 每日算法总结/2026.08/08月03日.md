## 第一题：石子游戏 III https://leetcode.cn/problems/stone-game-iii/description/?envType=daily-question&envId=2026-08-03

**思路：思维 + 一维dp。本题对于双方来说，其实都在追求自己得分 > 对方得分。但要同时维护两个变量就比较复杂，因此我们可以改为自己得分 - 对方得分 > 0，维护它们的差值。然后就可以写记忆化搜索了，也可额外翻译成dp**

**代码：**
```python
class Solution:
    def stoneGameIII(self, stoneValue: List[int]) -> str:
        n = len(stoneValue)

        @lru_cache(maxsize=None)
        def dfs(i: int) -> int:
            if i == n:
                return 0
            res = -inf
            s = 0
            for j in range(i, min(i + 3, n)):
                s += stoneValue[j]
                res = max(res, s - dfs(j + 1))
            return res

        diff = dfs(0)
        if diff == 0:
            return "Tie"
        return "Alice" if diff > 0 else "Bob"
```
