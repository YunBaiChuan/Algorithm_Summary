## 第一题：缺失的最小倍数 https://leetcode.cn/problems/smallest-missing-multiple-of-k/description/?envType=daily-question&envId=2026-08-25

**思路：模拟。根据题意模拟即可**

**Python代码：**
```python
class Solution:
    def missingMultiple(self, nums: List[int], k: int) -> int:
        nums = set(nums)
        for i in range(1, 105):
            if k * i not in nums:
                return k * i 
```

**Cpp代码：**
```cpp
class Solution {
public:
    int missingMultiple(vector<int>& nums, int k) {
        set<int> st(nums.begin(), nums.end());
        for (int i = 1; i <= 101; i++) {
            if (!st.count(i * k)) {
                return i * k;
            }
        }
        return -1;
    }
};
```

**思路：思维。题目其实就是要算每个数有多少个2的因子，最终答案就是这些数的2因子个数之和。然后计算2的因子个数其实就是这个数二进制状态下，末尾有几个连续的0**
