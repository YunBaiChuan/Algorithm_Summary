## 第一题：单面值组合的第 K 小金额 https://leetcode.cn/problems/kth-smallest-amount-with-single-denomination-combination/description/?envType=daily-question&envId=2026-08-21

**思路：二分答案 + 容斥原理。首先对于这类第K小问题，要想到两种解法：1.一个是Top-K的堆解法，对于第K小来说，就是维护大根堆；2.还有一个是二分答案，对于值为m来说，其元素个数就是m // x。当然，本题我们选择方法2，因为这个k非常大，量级是$10^9$，用堆的话会爆炸。对于check函数来说，我们先枚举它的子集/交集，然后算子集/交集的lcm，因为我们m // x和m // y这两个部分的元素是有可能产生交集的，所以说需要用容斥原理来去掉额外的交集部分，其实就是按照交集的大小来算，奇数+，偶数-。接着算出当前二分答案的cnt个数，判断其是否>= k即可，最终不断二分得到答案**

**代码：**
```python
class Solution:
    def findKthSmallest(self, coins: List[int], k: int) -> int:
        def check(m): # 检查该金额能有多少个数
            cnt = 0 
            for i in range(1, 1 << len(coins)): # 枚举子集
                lcm_res = 1 # 算子集的交集lcm
                for j, x in enumerate(coins):
                    if i >> j & 1:
                        lcm_res = lcm(lcm_res, x)
                        if lcm_res > m: # 剪枝优化
                            break
                else:
                    cnt += m // lcm_res if i.bit_count() % 2 else -(m // lcm_res) # 容斥原理，对于交集个数来说，奇数+，偶数-
            return cnt >= k 
        
        l, r = 0, min(coins) * k # 二分金额
        while l <= r:
            mid = (l + r) >> 1 
            if check(mid):
                r = mid - 1
            else:
                l = mid + 1 
        return l
```

## 第二题：不公平对局 https://www.nowcoder.com/practice/55cfa1c9f8c146fe81c3d676859b9d4e?channelPut=tracker2

**思路：概率dp。这题和一般的那种汇聚dp不一样，它是扩散dp。传统的汇聚dp就是$dp[i][j]$可能由多个状态转移过来，但是这题它是$dp[i][j]$可以往外转移到多个状态。然后就是需要算一个额外的归一化参数K，因为我们有三种情况，胜、负、平，他们的概率加起来应该是为1的，因此要进行归一化。算出dp数组之后，小红胜利的概率就是小紫吃了x子情况下的概率之和了**

**代码：**

mod = 10 ** 9 + 7

def solve():
    x = II()
    a1, b1 = MII()
    a2, b2 = MII()

    p1 = a1 * pow(b1, mod - 2, mod) % mod
    p2 = a2 * pow(b2, mod - 2, mod) % mod

    X = p1 * (1 - p2 + mod) % mod
    Y = p2 * (1 - p1 + mod) % mod
    Z = p1 * p2 % mod
    K = pow((X + Y + Z) % mod, mod - 2, mod) # 归一化

    dp = [[0] * (x + 1) for _ in range(x + 1)]
    dp[0][0] = 1

    for i in range(x + 1):
        for j in range(x + 1):
            if i == x or j == x: # 防止后面dp数组溢出
                continue

            # 扩散dp，而不是多个状态汇聚到dp[i][j]
            dp[i + 1][j] += dp[i][j] * X % mod * K % mod
            dp[i][j + 1] += dp[i][j] * Y % mod * K % mod
            dp[i + 1][j + 1] += dp[i][j] * Z % mod * K % mod

    ans = 0
    for i in range(x):
        ans = (ans + dp[i][x]) % mod
    print(ans)

    solve()
