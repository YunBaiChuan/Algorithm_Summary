## 第一题：从数组中移除最大值和最小值 https://leetcode.cn/problems/removing-minimum-and-maximum-from-array/description/?envType=daily-question&envId=2026-08-30

**思路：思维。首先算出mx和mn的索引位置，之后再算一下三种删除情况的操作数，其中的最小值就是答案**

**Python代码：**
```python
class Solution:
    def minimumDeletions(self, nums: List[int]) -> int:
        n = len(nums)

        mx = max(nums)
        mn = min(nums)
        l_mx = nums.index(mx) + 1
        r_mx = n - l_mx + 1
        l_mn = nums.index(mn) + 1
        r_mn = n - l_mn + 1

        p1 = max(l_mx, l_mn)
        p2 = max(r_mx, r_mn)
        p3 = min(l_mx + r_mn, l_mn + r_mx)

        return min(p1, p2, p3)
```

**Cpp代码：**
```cpp
class Solution {
public:
    int minimumDeletions(vector<int>& nums) {
        int mx = *max_element(nums.begin(), nums.end());
        int mn = *min_element(nums.begin(), nums.end());

        auto it1 = find(nums.begin(), nums.end(), mx);
        int l_mx = it1 - nums.begin() + 1, r_mx = nums.end() - it1;
        auto it2 = find(nums.begin(), nums.end(), mn);
        int l_mn = it2 - nums.begin() + 1, r_mn = nums.end() - it2;

        int p1 = max(l_mx, l_mn);
        int p2 = max(r_mx, r_mn);
        int p3 = min(l_mx + r_mn, l_mn + r_mx);

        return min(min(p1, p2), p3);
    }
};
```

## 第二题：终别 https://www.nowcoder.com/practice/80ef98a9f71640b98814ff692243716f?channelPut=tracker2

**思路：贪心 + 前后缀分解。首先贪心的计算前后缀累计操作数组pre和suf，具体来说，贪心策略如下：遍历一遍，如果当前位置不为0，那就应该进行操作，并且肯定是当前位置连着三个一起操作最优，操作次数就是当前位置从正数变为0的次数；然后就枚举分割点，因为我们有一次免费将相邻两个元素都变为0的操作，所以说枚举分割点之后，答案就是$pre[i - 1] + suf[i + 2]$中的最小值，跳过了中间两个元素**

def solve():

    a = LII()

        d = max(0, ar[i])
        if i == 0:

    ans = inf
