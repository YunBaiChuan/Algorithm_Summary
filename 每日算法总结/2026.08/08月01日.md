## 第一题：预测赢家 https://leetcode.cn/problems/predict-the-winner/description/?envType=daily-question&envId=2026-08-01

**思路：区间dp + 零和博弈。区间dp比较好想，状态转移时需要用到零和博弈，这个不太好想到。零和博弈简单来说就是我要最大化自己得分，就是最小化对方得分，就可以得到状态转移的两个大可能性了**

**代码：**
```python
class Solution:
    def predictTheWinner(self, nums: List[int]) -> bool:
        n = len(nums)
        # @lru_cache(maxsize=None)
        # def dfs(i, j):
        #     if i == j:
        #         return nums[i]
        #     if i == j - 1:
        #         return max(nums[i], nums[j])
        #     p1 = nums[i] + min(dfs(i + 2, j), dfs(i + 1, j - 1))
        #     p2 = nums[j] + min(dfs(i + 1, j - 1), dfs(i, j - 2))
        #     return max(p1, p2)

        # s = sum(nums)
        # a = dfs(0, n - 1)
        # b = s - a
        # return a >= b

                
        dp = [[0] * n for _ in range(n)]
        for i in range(n):
            dp[i][i] = nums[i]
        for i in range(n - 1):
            dp[i][i + 1] = max(nums[i], nums[i + 1])

        for i in range(n - 3, -1, -1):
            for j in range(i + 2, n):
                p1 = nums[i] + min(dp[i + 2][j], dp[i + 1][j - 1])
                p2 = nums[j] + min(dp[i + 1][j - 1], dp[i][j - 2])
                dp[i][j] = max(p1, p2)

        s = sum(nums)
        a = dp[0][-1]
        b = s - a 
        return a >= b
```

class BIT:
    def __init__(self, n):
        self.n = n
        self.tree = [0] * (n + 2)

    def add(self, i, v):
        while i <= self.n:
            self.tree[i] += v
            i += i & -i

    def sum(self, i):
        ans = 0
        while i > 0:
            ans += self.tree[i]
            i -= i & -i
        return ans

    def range(self, l, r, k):
        self.add(l, k)
        self.add(r + 1, -k)
