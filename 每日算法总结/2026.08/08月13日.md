## 第一题：绝对值博弈 https://www.nowcoder.com/practice/218d3386fde4430b8ddfd28dc3a411e7?channelPut=tracker2

**思路：思维 + 博弈。结论题，主要是知道一个关键结论：每次操作后得到的数是初始数组a的gcd倍数。因此，我们最终操作完之后得到的集合中，元素个数最多为mx / g，减去原来的n个，也就是可以操作的次数。此时就可以输出答案了，如果操作次数为奇数，那么Alice必胜，否则Bob**

**代码：**
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

using ll = long long;
const ll inf = 1e18;

int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}

void solve() {
    int n;
    cin >> n;

    int mx = 0;
    int g = 0;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        mx = max(mx, a[i]);
        g = gcd(g, a[i]);
    }

    cout << (((mx / g - n) & 1) ? "Alice" : "Bob") << '\n';
    
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```
