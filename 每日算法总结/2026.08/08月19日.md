## 第一题：安排电影院座位 https://leetcode.cn/problems/cinema-seat-allocation/description/?envType=daily-question&envId=2026-08-19

**思路：思维。首先观察题目可知，每行顶多安排2个组，如果说2-5中间被占了一个，安排数量-1；如果6-9中间被占了一个，安排数量-1；如果4-7中间都没被占，那么这个位置是可以安排人的，但由于我们前面两种情况会导致多减，因此这里要加回来。然后我们就这样模拟一遍，算出占座行的安排数，剩下没有占座的统一就是2个位子，再加上即可**

**代码：**
```python
class Solution:
    def maxNumberOfFamilies(self, n: int, reservedSeats: List[List[int]]) -> int:
        reservedSeats.sort()

        ans = 0
        init = 2
        pre_l = cnt = 1

        val = [False] * 2
        flag = True
        for l, r in reservedSeats:
            if l != pre_l:
                ans += init + flag if val[0] and val[1] and flag else init
                init = 2
                pre_l = l
                val = [False] * 2
                flag = True
                cnt += 1
            if r in [2, 3, 4, 5] and not val[0]:
                val[0] = True 
                init -= 1
            if r in [6, 7, 8, 9] and not val[1]:
                val[1] = True
                init -= 1
            if r in [4, 5, 6, 7]:
                flag = False
        
        ans += init + flag if val[0] and val[1] and flag else init

        ans += (n - cnt) * 2 
        return ans 
```

## 第二题：烙饼 https://www.nowcoder.com/practice/23c864e63f1a4645b6651b6c6983f529?channelPut=tracker2

**思路：思维 + 贪心。我最开始的想法是用最大堆来贪心做，其实就是先把烙饼时间建一个大根堆，然后每轮取m个饼出来，按照最小时间进行烤制，之后剩下没烤完的，就重新放回大根堆，如此反复。这个贪心策略其实是正确的，它可以得到最优时间T，并且复杂度为$mlogn$，这足以通过。但是他有个问题，即过于碎片化，导致它的操作数会非常大，也就是产生了很多没必要的操作，就过不了**

**以下是采用更优的时间填充方法，具体来说就是先算出每个机器最多运行的时间，也就是最优时间。这个其实就是最大烤制时间和总烤制时间的上取整平均值之间，算一个更大值，就是最多/最优时间。接着，我们就用每个饼去填这些机器就行，如果一个填满了就下一个饼，一个没填满就下一个机器，这样就能同时保证时间和操作都是最优的**

**代码：**

def solve():
    n, m = MII()
    a = LII()

    total = sum(a)
    max_time = max(a)
    T = max(max_time, (total + m - 1) // m)

    ans = []
    machine = 1
    start = 0

    for idx, time in enumerate(a, 1):
        remain = time

        while remain > 0:
            if start >= T:
                machine += 1
                start = 0
                continue

            available = T - start
            duration = min(remain, available)

            ans.append((idx, machine, start, start + duration))

            remain -= duration
            start += duration

    print(len(ans))
    for a, b, c, d in ans:
        print(a, b, c, d)

t = 1

    solve()
