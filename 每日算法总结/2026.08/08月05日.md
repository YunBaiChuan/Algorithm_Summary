## 第一题：移除可疑的方法 https://leetcode.cn/problems/remove-methods-from-project/description/?envType=daily-question&envId=2026-08-05

**思路：dfs。首先建图，然后用dfs标记所有可疑节点。接着判断一下有无非可疑节点调用某一个可疑节点的情况，如果有的话，说明无法删除任何可疑节点，否则可以删除。最终可以用set去掉可疑节点，然后转成list输出即可**

**代码：**
```python
class Solution:
    def remainingMethods(self, n: int, k: int, invocations: List[List[int]]) -> List[int]:
        g = [[] for _ in range(n)]
        for u, v in invocations:
            g[u].append(v)
        
        st = set()
        def dfs(i):
            st.add(i)
            for j in g[i]:
                if j not in st:
                    dfs(j)

        dfs(k)
        for u, v in invocations:
            if u not in st and v in st:
                return list(range(n))
        
        return list(set(range(n)) - st)
```
