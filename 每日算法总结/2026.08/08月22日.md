## 第一题：判断整除性 https://leetcode.cn/problems/check-divisibility-by-digit-sum-and-product/?envType=daily-question&envId=2026-08-22

**思路：模拟。按照题目模拟即可**

**代码1：Python**
```python
class Solution:
    def checkDivisibility(self, n: int) -> bool:
        return True if n % (sum(list(map(int, str(n)))) + prod(list(map(int, str(n))))) == 0 else False
```

**代码2：Cpp**
```cpp
class Solution {
public:
    bool checkDivisibility(int n) {
        int sn = 0, pn = 1;
        int tmp = n;
        while (n) {
            sn += n % 10;
            pn *= n % 10;
            n /= 10;
        }
        return tmp % (sn + pn) == 0 ? true : false;
    }
};
```

## 第二题：MoonLight的运算问题 https://www.nowcoder.com/practice/0bd9ece6af5e47e4ba54a40217dccdfe?channelPut=tracker2

**思路：贪心 + 取mod。这题比较好想，就是从到到尾遍历一遍a，然后判断下哪个操作的值更大，就取哪个。不过中途不取mod的话，数字会爆炸，导致超时。如果取了mod的话，又会导致大小关系的改变。所以说，我们一般对于res < mod来说就用上述的正常判断逻辑，否则肯定是用乘法比较好，就可以直接打个标签flag，后续直接乘法取mod即可。但这里面有个隐患就是可能会遇到0或者1，此时加法操作会更优，就额外判断下这种情况即可**

**Cpp代码：cpp就需要额外考虑溢出问题了，这个挺麻烦的。所以说这里就不再考虑python那样乘到上限再处理了，而是采用超过下限就处理**
```cpp
#include <iostream>
#include <vector>
using namespace std;

using ll = long long;
const ll inf = 1e18;
const ll mod = 998244353;

void solve() {
    ll n;
    cin >> n;
    vector<ll> a(n);
    for (auto& x: a) {
        cin >> x;
    }

    bool flag = true;
    ll res = 0;
    for (ll x: a) {
       if (flag || x < 2) {
            if (flag && res + x > 1) {
                flag = false;
            }
            res = (res + x) % mod;
            continue;
       }
       res = res * x % mod;
    }

    cout << res % mod << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    cin >> T;
    while (T--) {
        solve();
    }
}
```
