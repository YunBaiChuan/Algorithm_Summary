## 第一题：嘤嘤的新平衡树 https://www.nowcoder.com/practice/88f37b12bdf946348972d649164085d3?channelPut=tracker2

**思路：思维。根据题目描述可以推导出结论：答案为根节点的左右子树中较大值 * 2 + 1。并且对于整个树来说，这个结论都是成立的，所以说就可以用递归进行求解**

**代码：**
```python
mod = 10 ** 9 + 7

class Solution:
    def getTreeSum(self , tree: TreeNode) -> int:
        def dfs(node):
            if not node:
                return 0 
            return max(dfs(node.left), dfs(node.right)) * 2 + 1
        return dfs(tree) % mod
```
