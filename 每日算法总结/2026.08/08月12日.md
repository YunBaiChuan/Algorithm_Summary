## 第一题：最多 K 个重复元素的最长子数组 https://leetcode.cn/problems/length-of-longest-subarray-with-at-most-k-frequency/description/?envType=daily-question&envId=2026-08-12

**思路：不定长滑动窗口。很经典的题目，用cpp写也是差不多的，语法上也没有什么特别好说的**

**代码：**
```cpp
class Solution {
public:
    int maxSubarrayLength(vector<int>& nums, int k) {
        map<int, int> d;
        int ans = 0, l = 0;
        for (int r = 0; r < nums.size(); r++) {
            d[nums[r]]++;
            while (d[nums[r]] > k) {
                d[nums[l]]--;
                l++;
            }
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
};
```

## 第二题：小美的外卖订单编号 https://www.nowcoder.com/practice/91506d447f3445c999a27d556e530a37?channelPut=tracker2

**思路：思维。比较简单的取mod思维题，不过本题对于m == x的情况来说，结果应该是m，但取mod之后就会变成0，这里我们就可以对x - 1取mod，最后再+1即可**

**代码：**
```cpp
#include <iostream>
using namespace std;

using ll = long long;
const ll inf = 1e18;

void solve() {
    int q;
    cin >> q;
    int m, x;
    for (int i = 0; i < q; i++) {
        cin >> m >> x;
        cout << (x - 1) % m + 1 << '\n';
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```
