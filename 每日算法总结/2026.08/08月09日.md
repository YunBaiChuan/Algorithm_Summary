## 第一题：石子游戏 II https://leetcode.cn/problems/stone-game-ii/description/?envType=daily-question&envId=2026-08-09

**思路：思维 + 博弈dp。首先预处理后缀和，然后跑一个记忆化搜索即可。其中退出条件为所有石子能够全拿走，否则就找到对方拿石子最少的答案，并用当前后缀和的石子数减去的它，不断记忆化搜索得到答案**

**代码：**
```python
class Solution:
    def stoneGameII(self, s: List[int]) -> int:
        n = len(s)
        for i in range(n - 2, -1, -1):
            s[i] += s[i + 1]

        @cache
        def dfs(i: int, m: int) -> int:
            if i + m * 2 >= n:
                return s[i]
            return s[i] - min(dfs(i + x, max(m, x)) for x in range(1, m * 2 + 1))

        return dfs(0, 1)
```
