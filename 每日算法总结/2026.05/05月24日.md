## 第一题：跳跃游戏 V https://leetcode.cn/problems/jump-game-v/description/?envType=daily-question&envId=2026-05-24

**思路：单调栈预处理 + 逆向思考 + 记忆化搜索。思考一下如果从小到大跳行不行？答案是可以的，我们只需要每次跳左右最近的且满足距离<= d的最高位置即可。那这个最近的且满足距离<= d的最高位置可以用单调栈预处理出来，然后再用记忆化搜索，并且枚举每个位置为起点时起跳，其中的最大跳跃次数就是答案**

**代码：**
```python
class Solution:
    def maxJumps(self, arr: List[int], d: int) -> int:
        n = len(arr)

        st = []
        left = [-1] * n 
        for i, x in enumerate(arr):
            while st and arr[st[-1]] <= x:
                st.pop()
            if st and i - st[-1] <= d:
                left[i] = st[-1]
            st.append(i)
        
        st.clear()
        right = [-1] * n 
        for i in range(n - 1, -1, -1):
            x = arr[i]
            while st and arr[st[-1]] <= x:
                st.pop()
            if st and st[-1] - i <= d:
                right[i] = st[-1]
            st.append(i)
        
        @lru_cache(maxsize=None)
        def dfs(i):
            if i < 0:
                return 0 
            return max(dfs(left[i]), dfs(right[i])) + 1
        
        return max(dfs(i) for i in range(n))
```
