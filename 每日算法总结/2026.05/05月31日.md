## 第一题：摧毁小行星 https://leetcode.cn/problems/destroying-asteroids/description/?envType=daily-question&envId=2026-05-31

**思路：排序贪心。从小到大排序之后，遍历合并一遍即可**

**代码：**
```python
class Solution:
    def asteroidsDestroyed(self, mass: int, asteroids: List[int]) -> bool:
        asteroids.sort()
        for i, x in enumerate(asteroids):
            if x > mass:
                return False 
            mass += x 
        return True 
```

## 第二题：小红的素数合并 https://www.nowcoder.com/practice/d054a564a9084e9c93fc659553069a42?channelPut=tracker2

**思路：排序贪心 + 奇偶讨论。首先一个比较明显的贪心策略就是先排序，之后再进行首尾合并，这样能使得合并得到的元素尽可能小。不过有一点需要注意，当数组为偶数长度时，整个两两合并可以完成；但是为奇数长度时，会剩下一个无法合并的数，那我们其实可以把最大数作为多余的这个数，然后在剩下的n - 1个数中进行首尾合并即可**
