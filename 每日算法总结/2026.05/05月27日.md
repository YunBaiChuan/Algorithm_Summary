## 第一题：统计特殊字母的数量 II https://leetcode.cn/problems/count-the-number-of-special-characters-ii/description/?envType=daily-question&envId=2026-05-27

**思路：两个hash表。第一个hash表统计小写字母中最右侧索引，第二个hash表记录统计过的大写字母，最终$O(n)$遍历一遍即可**

**代码：**
```python
class Solution:
    def numberOfSpecialChars(self, word: str) -> int:
        ans = 0 

        d = defaultdict(lambda: inf)
        for i, x in enumerate(word):
            if x.islower():
                d[x] = i 
        
        vis = set()
        for i, x in enumerate(word):
            if x.isupper() and x not in vis:
                ans += 1 if i > d[x.lower()] else 0 
                vis.add(x)
        return ans 
```
