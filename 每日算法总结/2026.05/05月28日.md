## 第一题：最长公共后缀查询 https://leetcode.cn/problems/longest-common-suffix-queries/?envType=daily-question&envId=2026-05-28

**思路：思维，前缀树。本题要求的是最长后缀字符串匹配，那逆向思考一下，只需要用前缀树，把加入的字符串都进行翻转，之后再进行最长公共前缀匹配就行了**

**代码：**
```python
class Trie:
    def __init__(self, n):
        self.tree = [[0] * 26 for _ in range(n)]
        self.p = [0] * n
        self.e = [0] * n
        self.best = [(-1, -1)] * n  
        self.cnt = 1

    def insert(self, word, idx, length):
        cur = 1
        self.p[cur] += 1
        if self.best[cur][0] == -1 or length < self.best[cur][0]:
            self.best[cur] = (length, idx)
        
        for i in range(len(word)):
            path = ord(word[i]) - ord('a')
            if self.tree[cur][path] == 0:
                self.cnt += 1
                self.tree[cur][path] = self.cnt
            cur = self.tree[cur][path]
            self.p[cur] += 1
            if self.best[cur][0] == -1 or length < self.best[cur][0]:
                self.best[cur] = (length, idx)
        self.e[cur] += 1

    def query(self, word):
        cur = 1
        res = self.best[cur][1]
        for i in range(len(word)):
            path = ord(word[i]) - ord('a')
            if self.tree[cur][path] == 0:
                break
            cur = self.tree[cur][path]
            res = self.best[cur][1]
        return res


class Solution:
    def stringIndices(self, wordsContainer: List[str], wordsQuery: List[str]) -> List[int]:
        total = sum(len(w) for w in wordsContainer)
        trie = Trie(total + 2)
        
        for i, w in enumerate(wordsContainer):
            trie.insert(w[::-1], i, len(w))
        
        return [trie.query(q[::-1]) for q in wordsQuery]
```
