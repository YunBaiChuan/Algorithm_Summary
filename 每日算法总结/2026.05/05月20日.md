## 第一题：找到两个数组的前缀公共数组 https://leetcode.cn/problems/find-the-prefix-common-array-of-two-arrays/description/?envType=daily-question&envId=2026-05-20

**思路：位运算。比较简单的想法就是用两个set，然后算交集之后的长度，不过这样的空间复杂度是$O(n)$，那我们其实可以用两个变量来代替两个集合，用位运算来优化**

**代码：**
```python
class Solution:
    def findThePrefixCommonArray(self, A: List[int], B: List[int]) -> List[int]:
        n = len(A)
        ans = [0] * n 
        p = q = 0 
        for i in range(n):
            p |= 1 << A[i]
            q |= 1 << B[i]
            ans[i] = (p & q).bit_count()
        return ans 
```
