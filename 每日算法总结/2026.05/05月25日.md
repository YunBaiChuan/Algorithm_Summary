## 第一题：跳跃游戏 VII https://leetcode.cn/problems/jump-game-vii/description/?envType=daily-question&envId=2026-05-25

**思路：动态规划 + 前缀和优化。思路比较容易想到，具体代码实现需要花点功夫。考虑每个位置可能由那些位置转移过来，就是$[i - mx, i - mn]$，注意索引越界。如果这段区间中有一个能转移，那么当前位置可以转移，或者说就是这段累加和不为0/大于0即可，最终把dp表递推出来，判断结束位置是否能到达即可**

**代码：**
```python
class Solution:
    def canReach(self, s: str, minJump: int, maxJump: int) -> bool:
        n = len(s)
        dp = [False] * n
        sum_ = [0] * (n + 1)
        dp[0] = True
        sum_[1] = 1

        for j in range(1, n):
            dp[j] = j >= minJump and s[j] == '0' and sum_[j - minJump + 1] > sum_[max(j - maxJump, 0)]
            sum_[j + 1] = sum_[j] + dp[j]

        return dp[-1]
```

**思路：预处理 + 排序贪心。先把整个花费数组预处理出来，然后从小到大贪心买，就可以买最多物品。注意这个贪心和凑零钱不同，凑零钱是为了刚好凑出指定零钱，选择从大到小贪心，与这个不同**
