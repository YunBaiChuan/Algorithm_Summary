## 第一题：最长公共前缀的长度 https://leetcode.cn/problems/find-the-length-of-the-longest-common-prefix/?envType=daily-question&envId=2026-05-21

**思路：预处理hash + 暴力匹配。首先选一个数组并预处理出一个前缀hash表，接着再暴力枚举另一个数组的前缀，并且更新答案**

**代码：**
```python
class Solution:
    def longestCommonPrefix(self, arr1: List[int], arr2: List[int]) -> int:
        st = set()
        for s in map(str, arr1):
            for i in range(1, len(s) + 1):  # 枚举 s 的前缀长度
                st.add(s[:i])

        ans = 0
        for s in map(str, arr2):
            for i in range(1, len(s) + 1):  # 枚举 s 的前缀长度
                if s[:i] not in st:
                    break
                ans = max(ans, i)
        return ans
```

## 第二题：小苯的数组构造 https://www.nowcoder.com/practice/2f0c0611a74d476abe25cf9194858331?channelPut=tracker2

**思路：构造题。首先要满足构造出x，必然要有x | y = x才行；接着对于x == y并且n是偶数的情况来说，需要特别构造，也就是用lowbit ^ (x ^ lowbit)进行构造，然后再来n - 2个x，整个构造就可以满足条件；然后就是通用情况，我们可以根据n的奇偶性来构造，对于奇数来说就直接y，以及(n - 1)个x；对于偶数来说就是(x ^ y), x 然后(n - 2)个x，比较难想**
