**思路：构造题。大体思路容易想到，就是以全1为基础，然后分配前两个数以及最后一个数，如何恰好分配为k就不太好想。其实可以这样分配，在算好了全部分配为1的a和k之后，对于前两个数我们分配a - k，最后一个数分配2 * k - a，那么整体操作数就是k，恰好满足条件**

**代码：**

import sys

def solve():
    n, a, k = LII()

    if n == 1:
        if a == k:
            print(a)
        else:
            print(-1)
        return

    if (a + 1) // 2 > k:
        print(-1)
        return

    cnt = (n + 1) // 2
    ans = [1] * n
    a -= n
    k -= cnt

    if a < k or a > 2 * k:
        print(-1)
        return

    ans[0] += a - k
    ans[1] += a - k
    ans[-1] += 2 * k - a
    print(*ans)

t = 1
# t = II()
for _ in range(t):
    solve()
