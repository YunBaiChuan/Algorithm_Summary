## 第一题：检查数组是否经排序和轮转得到 https://leetcode.cn/problems/check-if-array-is-sorted-and-rotated/description/?envType=daily-question&envId=2026-05-23

**思路：思维。这题其实可以$O(n)$解决，注意到原数组是非递减的，并且经过轮转之后，就有可能会出现向下的断点，那么我们就可以先在末尾补一个nums[0]，之后检查断点数量是否<= 1即可**

**代码：**
```python
class Solution:
    def check(self, nums: List[int]) -> bool:
        nums = nums + [nums[0]]
        n = len(nums)
        cnt = 0 
        for i in range(1, n):
            if nums[i] < nums[i - 1]:
                cnt += 1
        return cnt <= 1
```

## 第二题：牛牛走迷宫 https://www.nowcoder.com/practice/001f545da20f4ce1a42fc0e0c67ef86e?channelPut=tracker2

**思路：bfs，回溯查找。bfs好想，主要是如何得到最小字典序的路径。我们其实可以在bfs的时候，按照'D', 'L', 'R', 'U'，也就是从小到大的字典序，此时的路线就是最小字典序的路线。并且额外维护一个from_dir数组，记录每个位置是从哪个方向来的。最后，往前回溯查找路线，然后翻转一下得到答案**

**代码：**
```python
import sys
from collections import deque

input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

DIR = {'D': (1, 0), 'L': (0, -1), 'R': (0, 1), 'U': (-1, 0)}

def solve():
    n, m = MII()
    a = [list(map(int, I())) for _ in range(n)]

    from_dir = [[None] * m for _ in range(n)]
    dist = [[-1] * m for _ in range(n)]
    q = deque([(0, 0)])
    dist[0][0] = 0

    while q:
        i, j = q.popleft()
        for d in ['D', 'L', 'R', 'U']:
            dx, dy = DIR[d]
            x, y = i + dx, j + dy
            if 0 <= x < n and 0 <= y < m and not a[x][y] and dist[x][y] == -1:
                dist[x][y] = dist[i][j] + 1
                from_dir[x][y] = d
                q.append((x, y))

    if dist[n - 1][m - 1] == -1:
        print(-1)
        return

    ans = []
    i, j = n - 1, m - 1
    while not (i == 0 and j == 0):
        d = from_dir[i][j]
        ans.append(d)
        dx, dy = DIR[d]
        i, j = i - dx, j - dy

    ans.reverse()

    print(dist[n - 1][m - 1])
    print(''.join(ans))

t = 1
# t = II()
for _ in range(t):
    solve()
```
