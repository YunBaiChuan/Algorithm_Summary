## 第一题：嘤嘤不想求异或喵 https://www.nowcoder.com/practice/0532a8d5f34640c7a1386f865c48b8e7?channelPut=tracker2

**思路：思维 + 打表找规律。可以发现从1到n异或结果的规律是由//4的除数xd和余数xm构成的：1.xm为0时，异或结果为xd * 4（其实就是x）；2.xm为1时，异或结果为1；3.xm为2时，异或结果为x + 1；4.xm为0时，异或结果为0。最终结果就是cal(r) ^ cal(l - 1)**

**代码：**

def cal(x):
    xd, xm = divmod(x, 4)
    if xm == 0:
        xor = xd * 4
    elif xm == 1:
        xor = 1
    elif xm == 2:
        xor = x + 1
    else:
        xor = 0
    return xor

def solve():
    l, r = MII()
    print(cal(r) ^ cal(l - 1))

# t = 1
t = II()
for _ in range(t):
    solve()
