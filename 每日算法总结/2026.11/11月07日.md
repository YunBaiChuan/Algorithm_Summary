**思路：排序 + 二分。由题意可知，这三种情况已经是一个全集了，因此我们只需要算出less和equal就可以通过整体的C(n, 2)来得到greater。那具体如何计算less和equal呢？排序二分。我们排完序之后，算当前元素需要的配对元素，由于进行了排序，因此这个配对元素的位置可以通过二分找到，并且限制j > i，也就是说配对元素位置要比当前位置大，这样才能防止重复统计。最终，输出答案即可**

**Python代码：**
```python
import sys
from bisect import bisect_left, bisect_right

input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''

def solve():
    n, k = MII()
    a = LII()

    a.sort()
    less = 0
    equal = 0
    for i in range(n):
        x = a[i]
        limit = (k + x - 1) // x
        p = bisect_left(a, limit, i + 1)
        less += p - (i + 1)
        if k % x == 0:
            y = k // x
            l = bisect_left(a, y, i + 1)
            r = bisect_right(a, y, i + 1)
            equal += r - l

    total = n * (n - 1) // 2
    greater = total - less - equal
    print(greater, equal, less)

t = 1
# t = II()
for _ in range(t):
    solve()
```
