## 第一题：最短唯一子数组 https://leetcode.cn/problems/smallest-unique-subarray/description/?envType=daily-question&envId=2026-11-25

**思路：字符串hash + 二分答案。二分答案容易想到，本题在长度上具有单调性。主要就是check函数怎么快速检查子数组是否出现过，这就需要用到字符串hash进行优化了**

**Python代码：**
```python
class Solution:
    def smallestUniqueSubarray(self, nums: List[int]) -> int:
        n = len(nums)  
        MOD1, MOD2 = 10**18 + 3, 10**18 + 9
        BASE1, BASE2 = 911382323, 972663749
        
        def build_hash(arr, mod, base):
            pre = [0] * (len(arr) + 1)
            pw = [1] * (len(arr) + 1)
            for i in range(len(arr)):
                pre[i+1] = (pre[i] * base + arr[i] + 1000000007) % mod
                pw[i+1] = (pw[i] * base) % mod
            return pre, pw
        
        pre1, pw1 = build_hash(nums, MOD1, BASE1)
        pre2, pw2 = build_hash(nums, MOD2, BASE2)
        
        def get_hash(l, r):
            h1 = (pre1[r] - pre1[l] * pw1[r-l] % MOD1 + MOD1) % MOD1
            h2 = (pre2[r] - pre2[l] * pw2[r-l] % MOD2 + MOD2) % MOD2
            return (h1, h2)
        
        def check(length):
            seen = set()
            dup = set()
            for i in range(n - length + 1):
                h = get_hash(i, i + length)
                if h in seen:
                    dup.add(h)
                else:
                    seen.add(h)
            return len(seen) > len(dup)
        
        lo, hi = 1, n
        ans = n
        while lo <= hi:
            mid = (lo + hi) >> 1
            if check(mid):
                ans = mid
                hi = mid - 1
            else:
                lo = mid + 1
        return ans
```
