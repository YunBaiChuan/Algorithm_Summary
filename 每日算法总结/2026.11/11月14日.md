## 第一题：最小正和子数组 https://leetcode.cn/problems/minimum-positive-sum-subarray/description/?envType=daily-question&envId=2026-11-14

**思路：前缀和 + 枚举。首先前缀和预处理出子数组和，接着枚举左右端点算答案**

**Python代码：**
```python
class Solution:
    def minimumSumSubarray(self, nums: List[int], l: int, r: int) -> int:
        n = len(nums)
        pre = [0] * (n + 1)
        for i, x in enumerate(nums):
            pre[i + 1] = pre[i] + x 
        
        inf = 10 ** 18
        ans = inf
        for i in range(1, n + 1):
            for j in range(i, n + 1):
                if l <= j - i + 1 <= r:
                    s = pre[j] - pre[i - 1]
                    if s < ans and s > 0:
                        ans = s 
        return ans if ans < inf else -1
```
