**思路：二分答案。首先一个很简单的想法就是用最大堆进行模拟，但这个复杂度为$O(klogn)$，必然会超时。而且用贪心进行k的%n优化无法证明，当然也是错误的。此时就要注意到如果我们操作次数越多，最大值就会变得越小，也就是具有单调性，并且题目所说的也符合“最小化最大值”这个二分答案的关键词。因此，我们可以对最大值进行二分答案，check函数就是遍历一遍a，算一下此时最大值mid，所花费的操作次数，并且判断其是否<= 要求的操作次数k即可。最终，输出答案**

**Python代码：**
```python
import sys

def I():
    return input()

def LFI():

fmax = lambda x, y: x if x > y else y

def solve():
    n, k, x = LII()
    a = LII()

    def check(mid):
        s = 0
        for v in a:
            if v > mid:
                s += (v - mid + x - 1) // x
        return s <= k

    l, r = -inf, max(a)
    while l <= r:
        mid = (l + r) >> 1
        if check(mid):
            r = mid - 1
        else:
            l = mid + 1
    print(l)

    solve()
```
