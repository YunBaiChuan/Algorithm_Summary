## 第一题：和为奇数的子数组数目 https://leetcode.cn/problems/number-of-sub-arrays-with-odd-sum/description/?envType=daily-question&envId=2026-11-15

**思路：思维 + 前缀和。对于子数组问题来说，前缀和是比较容易想到的，考虑怎么优化。主要是用奇偶性质进行优化，“奇 + 奇 = 偶”，“奇 + 偶 = 奇”，“偶 + 奇 = 奇”，“偶 + 偶 = 偶”，要统计和为奇数的子数组，那么就要算和自己当前和相反的子数组个数，因此统计cnt子数组和数组，初始s为0是偶数。最后，遍历一遍得到答案**

**Python代码：**
```python
class Solution:
    def numOfSubarrays(self, arr: list[int]) -> int:
        cnt = [1, 0]
        ans = s = 0 
        for x in arr:
            s = (s + x & 1) & 1
            ans += cnt[s ^ 1]
            cnt[s] += 1
        return ans % (10 ** 9 + 7)
```
