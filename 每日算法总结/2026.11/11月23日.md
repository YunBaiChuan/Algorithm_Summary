## 第一题：最后K个数的乘积 https://leetcode.cn/problems/product-of-the-last-k-numbers/description/?envType=daily-question&envId=2026-11-23

**思路：前缀积。主要是考虑有0的情况，他会导致前缀积后面都是0，让后面的操作失效。这里其实可以直接把前缀和数组重置掉，后续操作判断一下前缀和长度就知道是否出现过0了，很巧妙**

**Python代码：**
```python
class ProductOfNumbers:
    def __init__(self):
        self.p = [1]

    def add(self, num: int) -> None:
        if num != 0:
            self.p.append(self.p[-1] * num)
        else:
            self.p = [1]

    def getProduct(self, k: int) -> int:
        if len(self.p) <= k:
            return 0
        return self.p[-1] // self.p[-1 - k]
```
