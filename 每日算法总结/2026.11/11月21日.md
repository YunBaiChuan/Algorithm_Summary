## 第一题：小红的最大字典序 https://www.nowcoder.com/practice/cb88f306fab64d97b5b14bffa06ce537?channelPut=tracker2

**思路：贪心 + 思维。贪心比较好想到，具体来说就是答案的每一位是n个数字中某一位比较出来的最大值，也就是剩余数字中最大的第一位。但是实现起来就比较麻烦了，这里推荐一种简单的写法。首先写一个比较器转键函数，它主要是把比较结果转化为键/值；接着把元素变成字符串放到大根堆中，每次取其中的最大值出来，把第一位放到答案，然后切片剩余位放回最大堆，当然这里要验证下是否为空。最终遍历一遍得到答案**

**Python代码：**

import sys

input = lambda: sys.stdin.readline().strip()

    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y

def solve():
    n = II()
    a = LII()
    strs = [str(x) for x in a]

    k = cmp_to_key(lambda x, y: -1 if x > y else (1 if x < y else 0))

    h = [(k(s), s) for s in strs]
    heapq.heapify(h)

    ans = []
    while h:
        _, s = h[0]
        ans.append(s[0])
        s = s[1:]
        if s:
            heapq.heapreplace(h, (k(s), s))
        else:
            heapq.heappop(h)

    print(''.join(ans))

t = 1
# t = II()
for _ in range(t):
    solve()
