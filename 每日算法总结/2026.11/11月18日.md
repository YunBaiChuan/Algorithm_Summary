## 第一题：使二进制字符串变美丽的最少修改次数 https://leetcode.cn/problems/minimum-number-of-changes-to-make-binary-string-beautiful/description/?envType=daily-question&envId=2026-11-18

**思路：思维。可以发现题目要求其实只和长度为2的子串有关，只需要算一遍长度为2的子串修改次数，并且累加就是答案**

**Python代码：**
```python
class Solution:
    def minChanges(self, s: str) -> int:
        return sum(s[i] != s[i + 1] for i in range(0, len(s) - 1, 2))
```
