## 第一题： 最小操作次数使数组元素相等 II https://leetcode.cn/problems/minimum-moves-to-equal-array-elements-ii/description/?envType=daily-question&envId=2026-11-02

**思路：贪心。可以对任意一个数进行+-1操作，要使得所有数相同，并且操作次数最小。这有个经典结论：都变成中位数的时候，操作数最小。因此，我们排序之后找到中位数，然后算答案即可**

**Python代码：**
```python
class Solution:
    def minMoves2(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        mid = nums[n // 2]
        ans = 0 
        for x in nums:
            ans += abs(mid - x)
        return ans 
```
