## 第一题：最长的严格递增或递减子数组 https://leetcode.cn/problems/longest-strictly-increasing-or-strictly-decreasing-subarray/description/?envType=daily-question&envId=2026-11-12

**思路：一维dp + 思维。算一个dp数组，其中$dp[i]$表示以i为开头的最长严格递增子数组长度，然后dp数组的最大值就是整个数组的最长严格递增子数组长度。最后可以把这个逻辑封装，递减子数组就可以直接翻转原数组来进行计算得到，两者的最大值为答案**

**Python代码：**
```python
class Solution:
    def longestMonotonicSubarray(self, nums: List[int]) -> int:
        def solve(nums):
            n = len(nums)
            ans = [1] * n 
            for i in range(1, n):
                ans[i] += ans[i - 1] if nums[i] > nums[i - 1] else 0
            return max(ans)
        return max(solve(nums), solve(nums[::-1]))
```

## 第二题：复读姬 https://www.nowcoder.com/practice/494f727dc5664eae8c0a2175da66b4ca?channelPut=tracker2

**思路：分组循环 + 思维。首先分组循环预处理出连续段的值与长度，然后初始化答案为连续段中的最大长度，之后就可以枚举中间部分，如果删除的话，能否更新为更大的答案。最终，输出答案即可**
