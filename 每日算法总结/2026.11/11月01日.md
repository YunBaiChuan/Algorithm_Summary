## 第一题：最小操作次数使数组元素相等 https://leetcode.cn/problems/minimum-moves-to-equal-array-elements/description/?envType=daily-question&envId=2026-11-01

**思路：思维。题目操作是每次都让n - 1个数+1，那其实就等价于每次让1个数-1，因此答案就是总和s - n个数都变成最小值mn**

**Python代码：**
```python
class Solution:
    def minMoves(self, nums: List[int]) -> int:
        return sum(nums) - min(nums) * len(nums)
```
