## 第一题：修改两个元素的最小分数 https://leetcode.cn/problems/minimum-score-by-changing-two-elements/description/?envType=daily-question&envId=2026-11-19

**思路：思维。这题有三种情况：1.修改前两个值；2.修改后两个值；3.修改一前一后两个值。因此，排序之后取这三种情况中的最小值即可，我考虑的是3种情况哪种是最优的，其实就陷进去了，取min就行**

**Python代码：**
```python
class Solution:
    def minimizeSum(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        return min(nums[n-1] - nums[2], nums[n-3] - nums[0], nums[n-2] - nums[1])
```
