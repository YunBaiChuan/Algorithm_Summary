## 第一题：计算字符串的数字和 https://leetcode.cn/problems/calculate-digit-sum-of-a-string/description/?envType=daily-question&envId=2026-11-16

**思路：模拟。根据题意进行模拟即可，复杂度还是挺高的**

**Python代码：**
```python
class Solution:
    def digitSum(self, s: str, k: int) -> str:
        while len(s) > k:
            s = list(map(int, s))
            tmp = []
            for i in range(0, len(s), k):
                res = sum(s[i:i + k])
                tmp.append(res)
            s = ''.join(map(str, tmp))
        return ''.join(map(str, s))
```
