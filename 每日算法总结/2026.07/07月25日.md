**思路：思维 + 一维差分。首先通过把玩样例可知有以下贪心策略：优先砍h大的树，每次砍1长度。因此可以用大根堆来做，每次从堆顶弹出h最大的树，然后砍1长度，再放回大根堆。但这样做效率实在是太慢了，并且要考虑维护能砍多少长度**

**更优的做法是采用差分数组，我们首先将可以砍的长度放到差分数组进行维护，比如题目给定的$h$和$c$，其实能够砍的长度就是$[c + 1, h]$，反映到差分数组中就是$c + 1$处$+1$；$h + 1$处$-1$，接着算前缀和得到每个长度能被砍几次。具体计算答案用贪心，从后往前算，因为我们只有砍掉大长度，才能砍到小长度。每个长度我们就只砍1长度，个数就是统计到的个数，最终不超过m个情况下，累加答案，最终输出即可**

**代码：**

import sys
input = lambda: sys.stdin.readline().strip()

import math

def II():
    return int(input())

def MII():
    return map(int, input().split())

    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

MX = 10 ** 6

def solve():
    n, m = MII()
    a = [LII() for _ in range(n)]

    cnt = [0] * (MX + 5)
    for h, c in a:
        cnt[c + 1] += 1
        cnt[h + 1] -= 1

    for i in range(1, MX + 5):
        cnt[i] += cnt[i - 1]

    ans = 0
    for i in range(MX, 0, -1):
        tmp = fmin(m, cnt[i])
        m -= tmp
        ans += (2 * i - 1) * tmp
    print(ans)

t = 1
# t = II()
for _ in range(t):
    solve()
