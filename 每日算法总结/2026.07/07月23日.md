## 第一题：不同异或三元组的数目I https://leetcode.cn/problems/number-of-unique-xor-triplets-i/description/?envType=daily-question&envId=2026-07-23

**思路：思维 + 位运算。从题意可知，元素是1-n的排列，并且三元组异或元素可以任意选择。可以发现有以下规律：1.n <= 2时，答案就是其本身；2.n > 2时，三元组异或的种类由最高比特位决定，把玩样例可知，最高比特位的更低位都可以通过前面两个元素的异或构造出来，最终再异或上最高比特位，就可以获得新的异或和，因此答案为1 << max_length**

**代码：**
```python
class Solution:
    def uniqueXorTriplets(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 1 or n == 2:
            return n
        mx_length = n.bit_length()
        return (1 << mx_length)
```

## 第二题：加法入门 https://www.nowcoder.com/practice/bca90d96f18b4acea1bc7488d271a853?channelPut=tracker2

**思路：思维 + 数学。这题思维上比较好想到，把玩样例可知有以下规律：对于每个元素来说，它包含一个最短的交换满足区间，一旦>=该区间，此时交换后的不满足平衡条件。而这个最短区间其实就是该元素对应的层数，我们只需要快速算出它的层数，就可以解决这个问题了。对于这个问题来说，我们需要用到一种数学方法，即先算近似解，再通过上下条件的限制来逐步逼近真实解，这个思想挺巧妙的**
