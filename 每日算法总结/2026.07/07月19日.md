## 第一题：不同字符的最小序列 https://leetcode.cn/problems/smallest-subsequence-of-distinct-characters/description/?envType=daily-question&envId=2026-07-19

**思路：思维 + 栈。我们其实可以用一个栈来维护最小序列，并且由于我们的元素不能重复，所以说要用到vis。那如何判断此时的元素是否要弹出？有以下三点：1.栈非空，有元素才存在能否弹出这一说；2.栈顶元素要比当前元素更大，因为我们要的是最小序列；3.后续还有我要弹出的这个元素，因为我们是需要收集到所有元素的。对于第3点来说，我们需要知道后续有没有要弹出的这个元素，可以额外维护一个hash表，正向遍历的去掉对应元素，然后就可以$O(1)$知道后续是否还有这个元素了**

**代码：**
```python
class Solution:
    def smallestSubsequence(self, s: str) -> str:
        cnt = Counter(s)
        vis = set()

        st = []
        for x in s:
            cnt[x] -= 1
            if x in vis:
                continue 
            while st and st[-1] > x and cnt[st[-1]] != 0:
                vis.remove(st.pop())
            st.append(x)
            vis.add(x)
        
        return "".join(st)
```
