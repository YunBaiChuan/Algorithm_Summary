## 第一题：两个城市间路径的最小分数 https://leetcode.cn/problems/minimum-score-of-a-path-between-two-cities/?envType=daily-question&envId=2026-07-04

**思路：dfs/dijkstra。两种方法都行，不过这题用dfs就行，因为只需要找1到n路径上的最小权重**

**代码：**
```python
class Solution:
    def minScore(self, n: int, roads: List[List[int]]) -> int:
        inf = 10 ** 18 
        dis = [inf] * (n + 1)
        g = [[] for _ in range(n + 1)]
        for u, v, w in roads:
            g[u].append((v, w))
            g[v].append((u, w))
        
        vis = [False] * (n + 1)
        ans = inf 
        def dfs(i):
            vis[i] = True 
            nonlocal ans 
            for j, w in g[i]:
                ans = min(ans, w)
                if not vis[j]:
                    dfs(j)
                    
        dfs(1)
        return ans
```

## 第二题：过桥 https://www.nowcoder.com/practice/f7beafac285c4ef3895c1433dfd26a19?channelPut=tracker2

**思路：一维dp。题目数据量比较小，直接$O(n^2)$算一个一维dp就行。定义$dp[i]$表示到达位置i时，花费的最少时间；状态转移也比较简单，就根据题意说的进行状态转移，最终判断一下dp[-1]，然后输出答案即可。这题数据比较弱**

**代码：**
```python
import sys
input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''

'''

def solve():
    n = II()
    a = LII()

    dp = [inf] * n
    dp[0] = 0
    for i in range(n):
        if a[i] > 0:
            for j in range(i + 1, fmin(n, i + a[i] + 1)):
                dp[j] = fmin(dp[j], dp[i] + 1)
        else:
            for j in range(fmax(0, i + a[i]) + 1):
                dp[j] = fmin(dp[j], dp[i] + 1)

    print(dp[-1] if dp[-1] < inf else -1)

t = 1
# t = II()
for _ in range(t):
    solve()
```
