**思路：组合数学 + 贡献法。我们统计每一对元素，他们作为逆序对的贡献。但正着算比较困难，因此我们可以算出总的元素对数量，以及重复的元素对数量，这两个进行公式计算，就可以得到最终答案了**

**具体来说这个公式为$(n! / 2) * (C_n^2 - \sum C_{cnt[v]}^2)$，其实就是我们两个元素的先后排列概率是$1/2$，因此构成逆序对的排列数就是$n! / 2$，然后再*对应排列中的数量，即$(n! / 2) * C_n^2$。这个式子表示两元素不重复的情况下，逆序对的数量。但题目中有可能元素重复，因此要减去逆序排列中对应的数量，也就是$(n! / 2) * \sum C_{cnt[v]}^2$，两部分整合一下得到结果公式**

mod = 10 ** 9 + 7

def solve():
    n = II()
    a = LII()

    fact = 1
    for i in range(2, n + 1):
        fact = fact * i % mod

    total_pairs = n * (n - 1) // 2 % mod

    cnt = Counter(a)
    duplicate_pairs = 0
    for v in cnt.values():
        duplicate_pairs = (duplicate_pairs + v * (v - 1) // 2) % mod

    inv_2 = pow(2, mod - 2, mod)
    ans = fact * inv_2 % mod
    ans = ans * ((total_pairs - duplicate_pairs) % mod) % mod

    print(ans)

    solve()
