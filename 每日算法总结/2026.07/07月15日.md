## 第一题：tb的区间问题 https://www.nowcoder.com/practice/b44a8497acb04f5ba7ad59a99c7bc4d4?channelPut=tracker2

**思路：前后缀分解。首先预处理出整体和s，以及前缀和数组pre、后缀和数组suf；接着就枚举左边删i个，最多删除k个，因此右边删j个 = k - i；然后就遍历一遍，取s - 左边i个 - 右边j个中的最大值；最终输出即可，复杂度为$O(2n + k)$**

**当然本题用定长滑动窗口也是可以的，要左右一共删k个，那么窗口中就是n - k个元素，直接跑一个定长滑动窗口，算其中的最大和即可**

**代码：**
```python
import sys
input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''

'''

def solve():
    n, k = MII()
    a = LII()
    s = sum(a)

    pre = [0] * (n + 1)
    for i, x in enumerate(a):
        pre[i + 1] = pre[i] + x

    suf = [0] * (n + 1)
    for i in range(n - 1, -1, -1):
        suf[i] = suf[i + 1] + a[i]

    ans = 0
    for i in range(k + 1):
        j = k - i
        ans = max(ans, s - pre[i] - suf[n - j], s - pre[j] - suf[n - i])
    print(ans)

t = 1
# t = II()
for _ in range(t):
    solve()
```
