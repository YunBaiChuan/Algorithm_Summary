**思路：贪心 + 两次前缀和。首先从大到小排序，然后算一遍前缀和。这里排序之后可以特判一下，如果最大的数都<=0，必然后面的数也是如此，那么直接不操作，答案就是0。算完一遍前缀和之后，我们再算一遍前缀和，也就是要收集的答案。这里需要注意，由于题目要求每次选k >= 2个数，因此我们第一项pre[1]，即a[0]是不能单独算的。方便起见，可以直接将ans初始化为-pre[1]，这样后面正常算即可。如果遇到<=0的前缀和，就可以直接返回答案了；否则没有的话，就在外部输出即可。值得注意的是，第一遍算前缀和的时候不要取mod，因为此时负数取mod之后会变成整数，会干扰答案的计算**

mod = 10 ** 7 + 7

def solve():
    n = II()
    a = LII()

    a.sort(reverse=True)
    if a[0] <= 0:
        print(0)
        return

    pre = [0] * (n + 1)
    for i, x in enumerate(a):
        pre[i + 1] = pre[i] + x

    ans = -pre[1]
    for i, x in enumerate(pre):
        if x < 0:
            print(ans)
            return
        ans = (ans + x) % mod
    print(ans)

# t = 1
t = II()
for _ in range(t):
    solve()
