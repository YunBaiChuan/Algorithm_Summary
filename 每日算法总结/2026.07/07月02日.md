## 第一题：穿越网格图的安全路径 https://leetcode.cn/problems/find-a-safe-walk-through-a-grid/description/?envType=daily-question&envId=2026-07-02

**思路：最短路问题。其实就是要求从(0, 0)到(m - 1, n - 1)的最短距离，然后判断其是否严格 < health。那这就是一个单点最短距离，经典的算法就是dijkstra，不过本题权值只有0和1，因此可以用0-1 bfs优化成线性的复杂度**

**代码1：0-1 bfs**
```python
class Solution:
    def findSafeWalk(self, grid: List[List[int]], health: int) -> bool:
        inf = 10 ** 18
        m, n = len(grid), len(grid[0])

        dis = [[inf] * n for _ in range(m)]
        dis[0][0] = grid[0][0]
        q = deque([(grid[0][0], 0, 0)])
        while q:
            for _ in range(len(q)):
                d, i, j = q.popleft()
                if d > dis[i][j]:
                    continue 
                for x, y in (i + 1, j), (i - 1, j), (i, j + 1), (i, j - 1):
                    if 0 <= x < m and 0 <= y < n:
                        w = grid[x][y]
                        new_dis = d + w 
                        if new_dis < dis[x][y]:
                            dis[x][y] = new_dis 
                            if w == 0:
                                q.appendleft((new_dis, x, y))
                            else:
                                q.append((new_dis, x, y))

        return dis[-1][-1] < health
```

**代码2：dijkstra**
```python
class Solution:
    def findSafeWalk(self, grid: List[List[int]], health: int) -> bool:
        inf = 10 ** 18 
        m, n = len(grid), len(grid[0])
        
        dis = [[inf] * n for _ in range(m)]
        dis[0][0] = grid[0][0]
        h = [(grid[0][0], 0, 0)]
        while h:
            d, i, j = heappop(h)
            if d > dis[i][j]:
                continue 
            for x, y in (i + 1, j), (i - 1, j), (i, j + 1), (i, j - 1):
                if 0 <= x < m and 0 <= y < n:
                    new_dis = d + grid[x][y]
                    if new_dis < dis[x][y]:
                        dis[x][y] = new_dis 
                        heappush(h, (new_dis, x, y))

        return dis[-1][-1] < health
```

## 第二题：混乱的奶牛 https://www.nowcoder.com/practice/fc90c12a3c224f98aa04190b25a9f7cf?channelPut=tracker2

**思路：状压dp。注意到题目的n比较小，并且是算方案数，因此可以用状压dp解决**

**代码：**

def solve():

    a = [II() for _ in range(n)]

    for i in range(n):

    for mask in range(1 << n):
