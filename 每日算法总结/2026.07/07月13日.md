## 第一题：顺次数 https://leetcode.cn/problems/sequential-digits/description/?envType=daily-question&envId=2026-07-13

**思路：定长滑动窗口 + 二分。首先用定长滑动窗口预处理出所有满足条件的数，然后用二分切片，输出答案即可**

**代码：**
```python
tmp = []
init = "123456789"
for k in range(2, 10):
    res = 0 
    for r, x in enumerate(init):
        res = res * 10 + int(x)
        if r < k - 1:
            continue 
        tmp.append(res)
        res %= pow(10, k - 1)

class Solution:
    def sequentialDigits(self, low: int, high: int) -> List[int]:
        q, p = bisect_right(tmp, high), bisect_left(tmp, low)
        return tmp[p:q]
```

## 第二题：医生 https://www.nowcoder.com/practice/91875c1230ea4e8eb7ae4f3338e5be46?channelPut=tracker2

**思路：位运算。首先发现k比较小，因此可以用位运算预处理出所有药物组合可以覆盖的症状，然后对每个病人枚举预处理的药物组合，判断其能否覆盖病症，或者说病症是否为这个药物组合的子集。最终，输出结果即可**

**代码：**

import sys
input = lambda: sys.stdin.readline().strip()

inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

def solve():
    n, m = MII()

    patients = []
    for _ in range(n):
        s = I()
        patients.append(int(s, 2))

    k = II()
    drugs = []
    for _ in range(k):
        s = I()
        drugs.append(int(s, 2))

    total = 1 << k

    cover = [0] * total
    cnt = [0] * total

    for mask in range(total):
        cur = 0
        num = 0
        for j in range(k):
            if (mask >> j) & 1:
                num += 1
                cur |= drugs[j]
        cover[mask] = cur
        cnt[mask] = num

    for patient in patients:
        ans = inf
        for mask in range(total):
            if (cover[mask] | patient) == cover[mask]:
                ans = min(ans, cnt[mask])
        print(-1 if ans == inf else ans)
