## 第一题：数对的最大公约数和 https://leetcode.cn/problems/sum-of-gcd-of-formed-pairs/description/?envType=daily-question&envId=2026-07-16

**思路：模拟。按照题目说的进行模拟即可**

**代码：**
```python
class Solution:
    def gcdSum(self, nums: list[int]) -> int:
        n = len(nums)
        preMax = [0] * (n + 1)
        for i, x in enumerate(nums):
            preMax[i + 1] = max(preMax[i], x)

        prefixGcd = []
        for x, y in zip(preMax[1:], nums):
            prefixGcd.append(gcd(x, y))
        
        prefixGcd.sort()
        ans = 0 
        i, j = 0, len(prefixGcd) - 1
        while i < j:
            ans += gcd(prefixGcd[i], prefixGcd[j])
            i += 1
            j -= 1
        
        return ans 
```

## 第二题：牛牛和字符串的日常 https://www.nowcoder.com/practice/52fde23b237c44c892b6009c14d61e50?channelPut=tracker2

**思路：KMP。题目描述的问题和KMP可以解决的问题很相似，因此我们就套一个KMP模板，然后修改一下即可。简单说就是：首先把字符串s的nxt数组给处理出来，然后遍历每个字符串，对每个字符串进行匹配，由于我们只需要匹配上s前缀的最大长度，因此就在x[i] == s[j]里面加一个算最大前缀匹配长度的逻辑即可，算出最大匹配前缀长度后，累加到ans中，最终输出即可**
