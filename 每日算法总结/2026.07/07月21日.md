## 第一题：操作后最大活跃区段数 https://leetcode.cn/problems/maximize-active-section-with-trade-i/description/?envType=daily-question&envId=2026-07-21

**思路：思维。这题主要是考虑最大的"010"字符串中的零个数以及各部分连续1的个数（也就是总的1个数）。并不是一定要操作整个区间才能获得最终答案，陷入这个误区的话，这题基本上就做不出来了。因此，遍历一遍找连续段的长度，并且根据连续段的类型进行答案的累加计算**

**代码：**
```python
class Solution:
    def maxActiveSectionsAfterTrade(self, s: str) -> int:
        total1 = mx = cnt = 0
        pre0 = -inf
        for i, b in enumerate(s):
            cnt += 1
            if i == len(s) - 1 or b != s[i + 1]:
                if b == '1':
                    total1 += cnt
                else:
                    mx = max(mx, pre0 + cnt)
                    pre0 = cnt
                cnt = 0
        return total1 + mx
```
