## 第一题：删除被覆盖的区间 https://leetcode.cn/problems/remove-covered-intervals/description/?envType=daily-question&envId=2026-07-06

**思路：思维 + 排序贪心。首先将左端点从小到大排序，排除左端点影响，并且右端点在左端点相同时从大到小排序；接着遍历排好序后的区间，如果此时右端点超过最大，说明没覆盖到此区间ans + 1，否则说明完全包含了**

**代码：**
```python
class Solution:
    def removeCoveredIntervals(self, intervals: list[list[int]]) -> int:
        intervals.sort(key=lambda a: (a[0], -a[1]))
        ans = 0
        max_right = 0
        for _, r in intervals:
            if r > max_right:
                max_right = r
                ans += 1
        return ans
```

## 第二题：一种因子游戏 https://www.nowcoder.com/practice/7fc19053e4d74577a76ff64a61ae5647?channelPut=tracker2

**思路：二分图最大匹配/匈牙利算法。由题意可知，Bob获胜的充分条件为双方的牌一一匹配，也就是最大互质对数等于n。这其实是一个二分图最大匹配问题，我们首先根据能否互质进行二分图的创建，接着用二分图最大匹配算法/匈牙利算法得到最大匹配个数。如果最大匹配个数等于n，说明Bob获胜，否则Alice获胜**
