## 第一题：输入单词需要的最少按键次数 II https://leetcode.cn/problems/minimum-number-of-pushes-to-type-word-ii/description/

**思路：排序贪心，hash表。首先按照字符个数进行从大到小排序，这些字符放在前面可以使其按键次数尽量少。然后就进行编号，一共是8个空位，进行迭代填充编号。最终，收集字符串所需要的操作次数即可**

**代码：**
```python
class Solution:
    def minimumPushes(self, word: str) -> int:
        cnt = Counter(word)
        tmp = [k for k, v in sorted(cnt.items(), key=lambda x: -x[1])]

        d = defaultdict(int)
        limit, flag = 0, 1
        for x in tmp:
            limit += 1
            d[x] = flag 
            if limit % 8 == 0:
                flag += 1
        
        ans = 0 
        for k, v in cnt.items():
            ans += d[k] * v
        return ans 
```
