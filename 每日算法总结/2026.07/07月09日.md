## 第一题：针对图的路径存在性查询 I https://leetcode.cn/problems/path-existence-queries-in-a-graph-i/?envType=daily-question&envId=2026-07-09

**思路：思维 + 并查集。这题并查集比较容易想到，但是如何利用题目的非递减条件进行构建并查集时的优化，就不太好想到了。简单来说就是：只需要遍历一遍，如果前后两个元素的差值 <= maxDiff，就进行合并。为什么这样可行？假设有三个元素1 2 3，maxDiff为2，那么遍历过去1和2会合并，2和3会合并，此时1和3就已经是合并状态了，不需要再判断1和3能否合并，达到优化效果**

**代码：**
```python
class Solution:
    def pathExistenceQueries(self, n: int, nums: List[int], maxDiff: int, queries: List[List[int]]) -> List[bool]:
        fa = list(range(n))
        def find(x):
            if x != fa[x]:
                fa[x] = find(fa[x])
            return fa[x]
        for i in range(1, n):
            fx = find(i - 1)
            fy = find(i)
            if nums[i] - nums[i - 1] <= maxDiff:
                fa[fy] = fx
        return [fa[u] == fa[v] for u, v in queries]
```

## 第二题：切割01串 2.0 https://www.nowcoder.com/practice/91805e62c5754e199089a0d6031de415?channelPut=tracker2

**思路：划分dp + 前缀和优化。预处理出前缀0数组及前缀1数组，然后再跑一个划分dp即可。定义$dp[i][j]$表示子串$s[i:j+1]$（长度为 $j-i+1$）在最优策略下最多能执行的切割次数；状态转移就是枚举切割点，算最大的切割次数，其中需要用到前面预处理的两个前缀和数组。最终，输出答案即可**
