## 第一题：游游的水果大礼包 https://www.nowcoder.com/practice/fa0519c4469f4241bbdb7eabe7e3b295?channelPut=tracker2

**思路：枚举。直接贪心先算a, b中价值更大的一方是不对的，比如样例4 2 2 3，正解应该是两个1礼包为4价值，但用前面说的贪心的话，就是一个2礼包为3，不是最优解。因此我们就需要枚举一个礼包的个数，这里我枚举的是1礼包的个数，然后再算2礼包的个数，并且得到当前枚举的总价值，不断取max即可得到答案**

**代码：**
```python
import sys
input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''

'''

def solve():
    n, m, a, b = LII()

    def cal(n, m, x):
        ans = 0
        ans += a * x
        n -= 2 * x
        m -= x

        cnt2 = fmin(n, m // 2)
        ans += b * cnt2
        return ans

    ans = 0
    for x in range(fmin(n // 2, m) + 1):
        ans = fmax(ans, cal(n, m, x))
    print(ans)

t = 1
# t = II()
for _ in range(t):
    solve()
```
