## 第一题：恢复网络路径 https://leetcode.cn/problems/network-recovery-pathways/description/?envType=daily-question&envId=2026-07-03

**思路：二分答案 + 图dp。二分答案比较好想，主要是check函数的图dp怎么写。首先建图，我们可以根据边的左右端点均在线才进行连接，最终得到一个连通图；接着check函数就比较好写了，直接从0开始dfs遍历，并且记录路径中的最小权重即可**

**代码：**
```python
class Solution:
    def findMaxPathScore(self, edges: List[List[int]], online: List[bool], k: int) -> int:
        n = len(online)
        g = [[] for _ in range(n)]
        max_wt = -1
        for x, y, wt in edges:
            if online[x] and online[y]:
                g[x].append((y, wt))
                if x == 0:
                    max_wt = max(max_wt, wt)

        def check(lower: int) -> bool:
            @cache
            def dfs(x: int) -> int:
                if x == n - 1:  # 到达终点
                    return 0
                res = inf
                for y, wt in g[x]:
                    if wt >= lower:
                        res = min(res, dfs(y) + wt)
                return res
            return dfs(0) <= k

        left, right = -1, max_wt + 1
        while left + 1 < right:
            mid = (left + right) // 2
            if check(mid):
                left = mid
            else:
                right = mid
        return left
```

## 第二题：牛牛的说谎机器 https://www.nowcoder.com/practice/58e2986ee29e4e62b33c11c013426a3c?channelPut=tracker2

**思路：思维 + 差分数组。首先题目要求最多的错误指令，但是给定的操作区间我们要枚举哪些错误的话，时间复杂度会炸；逆向考虑最多的错误指令其实就是最少的正确指令，那正确指令就好算了，也就是所有给定的指令都是正确的，那具体最少的正确指令数怎么计算？其实就是用差分数组进行维护，最终得到差分数组，并且算一个前缀和，其中的最小值就是最少的正确指令，用总的指令m - right_mn就是最多的错误指令，然后个数的话两者相同**
