## 第一题：图像重叠 https://leetcode.cn/problems/image-overlap/?envType=daily-question&envId=2026-09-13

**思路：模拟。根据题意进行模拟，即暴力枚举dx，dy，然后算移动后的匹配个数，其中的最大值就是答案**

**Python代码：**
```python
class Solution:
    def largestOverlap(self, img1: List[List[int]], img2: List[List[int]]) -> int:
        n = len(img1)
        ans = 0
        for dx in range(1 - n, n):
            for dy in range(1 - n, n):
                cnt1 = 0
                for i in range(max(-dx, 0), min(n - dx, n)):
                    for j in range(max(-dy, 0), min(n - dy, n)):
                        cnt1 += img1[i][j] * img2[i + dx][j + dy]
                ans = max(ans, cnt1)
        return ans
```
