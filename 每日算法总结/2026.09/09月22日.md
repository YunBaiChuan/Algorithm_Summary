**思路：思维 + 推式子。由题意可知，我们能够得到公式如下：$f(n) = n + f((n - 1) // 2)$，然后while算一遍即可得到答案**

**Python代码：**

mod = 10 ** 9 + 7

def solve():
    n = II()
    ans = 0
    while n > 0:
        ans = (ans + n) % mod
        n = (n - 1) // 2
