## 第一题：替换字符串中的括号内容 https://leetcode.cn/problems/evaluate-the-bracket-pairs-of-a-string/?envType=daily-question&envId=2026-09-26

**思路：hash表 + 模拟。根据题意进行hash表的字符串模拟并输出即可**

**Python代码：**
```python
class Solution:
    def evaluate(self, s: str, knowledge: List[List[str]]) -> str:
        d = {}
        for k, v in knowledge:
            d[k] = v 
        
        n = len(s)
        i = 0
        tmp = ""
        ans = ""
        flag = False
        while i < n:
            if s[i] == ')':
                flag = False 
                ans += d.get(tmp, '?')
                tmp = ""
            if flag:
                tmp += s[i]
            elif not flag and s[i].isalpha():
                ans += s[i]
            if s[i] == '(':
                flag = True 
            i += 1
        
        return ans 
```
