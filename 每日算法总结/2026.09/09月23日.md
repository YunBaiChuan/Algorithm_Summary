## 第一题：将 x 减到 0 的最小操作数 https://leetcode.cn/problems/minimum-operations-to-reduce-x-to-zero/description/?envType=daily-question&envId=2026-09-23

**思路：前后缀分解 + 二分查找。这个方法比较好想，不过时间复杂度是$O(nlog_n)$，比较友好的是在这个数据下也能通过。首先预处理出前后缀和数组，之后枚举后缀和数组x，再用二分查找优化前缀数组查找tg - x，然后判断下找的位置对不对，它包含三个部分：1.索引不越界；2.数值正确；3.不超过枚举i位置。满足这几个条件就可以进行答案的更新，最终输出答案即可**

**Python代码：**
```python
class Solution:
    def minOperations(self, nums: list[int], tg: int) -> int:
        n = len(nums)

        pre = [0] * (n + 1)
        for i, x in enumerate(nums):
            pre[i + 1] = pre[i] + x 
        
        suf = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            suf[i] = suf[i + 1] + nums[i]
        
        ans = inf 
        for i, x in enumerate(suf):
            j = bisect_left(pre, tg - x)
            if j < n + 1 and pre[j] == tg - x and j <= i:
                ans = min(ans, n - i + j)
        return ans if ans < inf else -1
```
