## 第一题：反转每对括号间的子串 https://leetcode.cn/problems/reverse-substrings-between-each-pair-of-parentheses/description/?envType=daily-question&envId=2026-09-27

**思路：栈 + 模拟。用两个栈进行$O(n^2)$模拟即可**

**Python代码：**
```python
class Solution:
    def reverseParentheses(self, s: str) -> str:
        st = []
        for c in s:
            if c != ')':
                st.append(c)
            else:
                tmp = []
                while st and st[-1] != '(':
                    tmp.append(st.pop())
                st.pop()
                st += tmp 
        return ''.join(st)
```
