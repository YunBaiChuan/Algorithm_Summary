## 第一题：走一个大整数迷宫 https://www.nowcoder.com/practice/5e28adbc58a443808dead63044a5a079?channelPut=tracker2

**思路：思维 + 分层图bfs。首先，我们不能直接算出权重$c[i][j]$，因为这个值实在是太大了，他叠了两层指数。并且题目说了有取mod操作，所以说我们其实只需要对$a[i][j]$取mod即可得到权重$c[i][j]$；然后就可以写分层图bfs了，它的每个deque元素有4个参数：s, i, j, d。这里要额外加上d，因为我们答案的dis不是同意递增的，而是对于每一个元素来说逐个进行递增的。其他写法就差不多了，最终输出答案即可**

**Python代码：**

import sys
from collections import deque

input = lambda: sys.stdin.readline().strip()

import math

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y

def solve():
    n, m, p = LII()
    a = [LII() for _ in range(n)]
    b = [LII() for _ in range(n)]

    mod = p - 1
    c = [[a[i][j] % mod for j in range(m)] for i in range(n)]

    q = deque([(c[0][0], 0, 0, 0)])
    vis = {(c[0][0], 0, 0)}

    while q:
        s, i, j, d = q.popleft()
        if i == n - 1 and j == m - 1 and s % mod == 0:
            print(d)
            return
        for x, y in (i + 1, j), (i - 1, j), (i, j + 1), (i, j - 1):
            if 0 <= x < n and 0 <= y < m:
                ns = (s + c[x][y]) % mod
                if (ns, x, y) not in vis:
                    vis.add((ns, x, y))
                    q.append((ns, x, y, d + 1))
    print(-1)

t = 1
# t = II()
for _ in range(t):
    solve()
