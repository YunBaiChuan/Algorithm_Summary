**思路：思维。题目描述的意思其实是k进制表示数n，然后其表示位上的最大值就是最少分解个数，即答案。因此，我们就不断取mod最大值，然后不断//k，就可以得到最终答案了**

**Python代码：**
```python
import sys
input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y

def solve():
    n, k = MII()
    if k == 1:
        print(1)
        return

    ans = 0
    while n:
        ans = max(ans, n % k)
        n //= k
    print(ans)

# t = 1

    solve()
```
