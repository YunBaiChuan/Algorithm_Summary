## 第一题：矩形重叠 https://leetcode.cn/problems/rectangle-overlap/description/?envType=daily-question&envId=2026-09-14

**思路：思维。一个比较简单的想法是用二维差分，然后算个前缀和找有没有2。但这个方法的复杂度太高了，会同时爆空间和时间。因此，我们可以考虑x与y方向分别进行重叠判断，即将x和y方向分开，分别判断一维上是否有相交。最后，两个方向都相交时，其对应的二维矩阵才会相交**

**Python代码：**
```python
class Solution:
    def isIntervalOverlap(self, l1: int, r1: int, l2: int, r2: int) -> bool:
        return max(l1, l2) < min(r1, r2)

    def isRectangleOverlap(self, rec1: list[int], rec2: list[int]) -> bool:
        return self.isIntervalOverlap(rec1[0], rec1[2], rec2[0], rec2[2]) and \
               self.isIntervalOverlap(rec1[1], rec1[3], rec2[1], rec2[3])
```
