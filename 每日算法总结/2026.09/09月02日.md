## 第一题：区间因数个数之和 https://www.nowcoder.com/practice/1ae57482db684866b918c66dbc36cb97?channelPut=tracker2

**思路：数学 + 分块。首先算$1 \to n$之间$k$的倍数有几个，其公式为$n // k$；扩展一下，我们要算$1 \to n$之间的因子个数总和为多少怎么算？其实就是用上面的公式，对于$k \in [1, n]$，累加其因子个数就可以得到答案。但这个时间复杂度为$O(n)$，对于本题$10^{12}$量级来说，必然超时。我们观察每个$k$对应的因子数可以发现，数字呈现出了规律性，具体来说就是每一块数字相同，然后逐步递减下去。因此，我们就可以用分块来算贡献，最终将时间复杂度降到$O(\sqrt{n})$，就可以通过了**

**Cpp代码：**
```cpp
#include <iostream>
using namespace std;

using ll = long long;
const ll inf = 1e18;

ll cal(ll x) {
    ll ans = 0;
    ll l = 1;
    while (l <= x) {
        ll v = x / l;
        ll r = x / v;
        ans += v * (r - l + 1);
        l = r + 1;
    }
    return ans;
}

void solve() {
    ll l, r;
    cin >> l >> r;
    cout << cal(r) - cal(l - 1) << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin >> T;
    while (T--) {
        solve();
    }
}
```
