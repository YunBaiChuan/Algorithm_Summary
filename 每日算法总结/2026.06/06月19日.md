## 第一题：清楚姐姐的布告规划 https://www.nowcoder.com/practice/d9fff2d0c38940df865ce746d263316e?channelPut=tracker2

**思路：01背包 + 思维。首先题目要求出恰好贴满n至少需要多少张海报，这个比较容易看出来是一个恰好01背包问题；接着需要考虑一个限制，也就是题目所说的海报之间不重叠，这个就需要在j的部分进行逻辑添加，将j的范围从$[n, 0]$，限制到$[fmin(v + i, n), fmax(v, i + 1) - 1]$，其他板子部分不变；最终，输出$dp[-1]$即可**

**代码：**
```python
import sys
input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''

'''

def solve():
    n = II()
    a = LII()

    dp = [inf] * (n + 1)
    dp[0] = 0
    for i in range(n):
        v = a[i]
        for j in range(fmin(v + i, n), fmax(v, i + 1) - 1, -1):
            if j >= v:
                dp[j] = fmin(dp[j], dp[j - v] + 1)

    print(dp[-1] if dp[-1] < inf else -1)

# t = 1
t = II()
for _ in range(t):
    solve()
```
