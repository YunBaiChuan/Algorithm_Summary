**思路：思维，差分优化。对于本题来说，最终只有一个区间查询，因此我们其实可以不用算出整个差分数组。只需要每次操作时，求一下两个区间的交集，就可以算出最终的操作结果，然后再加上原数组l到r的值，就是答案。当然，这是对于最终为单个区间查询的差分优化；如果是单个点查询，我们也可以这样做。那么对于多次区间查询，或者多个单点查询来说，上面的优化就不行了，得用完整的差分数组**

**代码：**
```python
import sys
input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''

'''

def solve():
    n, m = MII()
    a = [0] + LII()

    tmp = []
    for _ in range(m):
        op, L, R, p = LII()
        tmp.append((op, L, R, p))

    l, r = MII()
    ans = 0
    for op, L, R, p in tmp:
        if op == 1:
            ans -= p * (fmin(R, r) - fmax(L, l) + 1)
        else:
            ans += p * (fmin(R, r) - fmax(L, l) + 1)

    for i in range(l, r + 1):
        ans += a[i]
    print(ans)

t = 1
# t = II()
for _ in range(t):
    solve()
```
