## 第一题：九倍平方数 https://www.nowcoder.com/practice/032c72fab5fe4a2ea8e11d40378a493d?channelPut=tracker2

**思路：思维 + 贪心。首先要注意到一个性质：一个数% 9 == 0说明这个数的各个数位之和% 9 == 0；接着根据题意可知，我们的操作只有2 -> 4，增加2；以及3 -> 9，增加6有效，那就可以先统计出数位中的2和3；那最终问题就变成利用增加2和增加6，使得9 - 数位之和 % 9能够被凑出来**

**这里面涉及到奇偶性，由于增加2和增加6都是偶数，那么当9 - 数位之和 % 9为偶数时，直接凑即可；为奇数时我们就要+9，使其变成偶数，然后进行操作。那具体凑的过程，就是一个非常经典的贪心，先用大的开始凑，然后再用小的凑，最终判断一下是否凑出来即可**

**代码：**
```python
import sys
input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''
2 -> 4 增加2
3 -> 9 增加6
'''

def solve():
    nums = list(map(int, I()))
    s = sum(nums)
    if s % 9 == 0:
        print("YES")
        return

    nums_2 = nums.count(2)
    nums_3 = nums.count(3)

    mod = 9 - s % 9
    if mod & 1:
        mod += 9

    while mod >= 6 and nums_3 >= 1:
        mod -= 6
        nums_3 -= 1

    while mod >= 2 and nums_2 >= 1:
        mod -= 2
        nums_2 -= 1

    if not mod:
        print("YES")
    else:
        print("NO")

# t = 1
t = II()
for _ in range(t):
    solve()
```
