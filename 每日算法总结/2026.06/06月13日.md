**思路：思维 + 贪心。首先数组a的值不重要，并且题目说了a中的值互不相同，因此考虑数组b即可；对于b来说，我们首先Counter()一下里面的元素，接着可以特判一下：如果一个元素只有一个，那他无法被交换，直接输出-1即可；然后对于其他元素，我们就进行贪心地交换，简单来说就是前面和后面进行交换，不过这个要分一下奇偶：如果是偶数，那交换次数就是v // 2；如果是奇数，那他中间元素不变，需要额外交换一次为v // 2 + 1。可以综合一下，就是v // 2上取整，即(v + 1) // 2**
