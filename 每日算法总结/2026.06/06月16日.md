**思路：Miller-Rabin算法，以下简称mr算法。mr算法主要是一种概率型素数判定算法，他相比于一般的根号算法来说，要快几个量级。其核心思想是利用小费马定理（加强版），进行多组基测试，并且每次测试误判为素数的概率为$1/4$（这是个结论，记住即可），这里的基就是用几个小素数进行测试，本题选了6个质数，测试误判率就是$(1 / 4)^6$，准确率非常高，并且只需要进行6轮测试即可，比一般的根号算法快得多**

def mr(n):
    if n < 2:
        return False
    for p in (2, 3, 5, 7, 11, 13):
        if n % p == 0:
            return n == p
    d = n - 1
    s = 0
    while d % 2 == 0:
        s += 1
        d //= 2
    for a in (2, 3, 5, 7, 11, 13):
        if a >= n:
            continue
        x = pow(a, d, n)
        if x == 1 or x == n - 1:
            continue
        for _ in range(s - 1):
            x = pow(x, 2, n)
            if x == n - 1:
                break
        else:
            return False
    return True
