## 第一题：最大子数组总值I https://leetcode.cn/problems/maximum-total-subarray-value-i/description/?envType=daily-question&envId=2026-06-09

**思路：思维。要使得mx最大，mn最小，那么所选范围越大越好，其实就是选整个数组，并且题目不限制同一个数组选多次，因此答案就是k * (mx - mn)**

**代码：**
```python
class Solution:
    def maxTotalValue(self, nums: List[int], k: int) -> int:
        return k * (max(nums) - min(nums))
```

## 第二题：采矿时间到 https://www.nowcoder.com/practice/93b9d4a3419e481891384d81977d0cac?channelPut=tracker2

**思路：模拟，贪心。首先收集所有矿石需要采集的次数，然后再从小到大贪心遍历一遍即可。需要注意一点，在收集采集次数的时候，如果说一列的两个都是矿石，那么采集次数应该是1，1；而不是1，2。因为采集了一个之后，另一个可以一步到位**
