## 第一题：签到题 https://www.nowcoder.com/practice/e0bf0735e1cd4dffa4460685983e2028?channelPut=tracker2

**思路：贪心/动态规划dp。正向dp，或者反向贪心都可以做。这里采用正向dp，状态转移有两个：1.如果比当前数更大的元素个数 >= m - v，那么dp[i] = fmin(m, v)；2.如果更少的话，dp[i] = mx，这里的mx指的是它前面dp值中的最大值。最终，遍历一遍，答案就是mx**

**代码：**
```python
import sys

import math

    return input()

    return int(input())

    return map(int, input().split())

    return input().split()

    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''

'''

def solve():
    n, m = MII()
    a = LII()
    cnt = Counter(a)

    mx = pre = 0
    dp = [0] * len(cnt)
    for i, (k, v) in enumerate(sorted(cnt.items())):
        pre += v
        if n - pre >= m - v:
            dp[i] = fmin(m, v)
        else:
            dp[i] = mx
        mx = fmax(mx, dp[i])
    print(mx)

t = 1
# t = II()
for _ in range(t):
    solve()
```

## 第二题：链表最大孪生和 https://leetcode.cn/problems/maximum-twin-sum-of-a-linked-list/description/?envType=daily-question&envId=2026-06-14

**思路：链表操作。首先需要用到两个子函数：1.链表找中点，这个就是用快慢指针，一个走一步，一个走两步，当fast指针走到末尾的时候，慢指针指向中点；2.链表的反转，需要用到三个指针pre，cur以及临时的nxt。那最大孪生和就是，先找到中点，然后反转中点及其后面的链表，最终两个链表同时遍历，找mx即可**

**代码：**
```python
class Solution:
    # 876. 链表的中间结点
    def middleNode(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        return slow

    # 206. 反转链表
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        pre, cur = None, head
        while cur:
            nxt = cur.next
            cur.next = pre
            pre = cur
            cur = nxt
        return pre

    def pairSum(self, head: Optional[ListNode]) -> int:
        mid = self.middleNode(head)
        head2 = self.reverseList(mid)

        ans = 0
        while head2:
            ans = max(ans, head.val + head2.val)
            head = head.next
            head2 = head2.next
        return ans
```
