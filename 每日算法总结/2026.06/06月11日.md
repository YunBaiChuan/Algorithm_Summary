## 第一题：给边赋权值的方案数 I https://leetcode.cn/problems/number-of-ways-to-assign-edge-weights-i/description/?envType=daily-question&envId=2026-06-11

**思路：数学 + 树的高度。首先题目说了任意一个最深的叶子节点算即可，那其实就是k = 树的高度 - 1，这个直接初始化d = 0提前减去即可；接着问题就转化为在k个数字中，选奇数个的方案数。这是个结论：方案数为$2^{k-1}$。简单证明以下就是：先从k个中取出1个，然后剩下的k - 1个数选或不选就是$2^{k-1}$种方案，不管选或不选之后得到的数为奇数还是偶数，先前取出的那个数都可以使其满足条件，因此总的方案数就是$2^{k-1}$；最后用一下公式即可得到答案**

**代码：**
```python
class Solution:
    def assignEdgeWeights(self, edges: List[List[int]]) -> int:
        MOD = 10 ** 9 + 7
        n = len(edges) + 1
        g = [[] for _ in range(n + 1)]
        for x, y in edges:
            g[x].append(y)
            g[y].append(x)

        def dfs(x: int, fa: int) -> int:
            d = 0
            for y in g[x]:
                if y != fa:
                    d = max(d, dfs(y, x) + 1)
            return d

        k = dfs(1, 0)
        return pow(2, k - 1, MOD)
```
