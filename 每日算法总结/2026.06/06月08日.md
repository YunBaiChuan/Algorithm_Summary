## 第一题：根据给定数字划分数组 https://leetcode.cn/problems/partition-array-according-to-given-pivot/description/?envType=daily-question&envId=2026-06-08

**思路：模拟。创建三个数组，然后遍历一遍，拼接输出即可**

**代码：**
```python
class Solution:
    def pivotArray(self, nums: List[int], pivot: int) -> List[int]:
        left, mid, right = [], [], []
        for x in nums:
            if x < pivot:
                left.append(x)
            elif x == pivot:
                mid.append(x)
            else:
                right.append(x)
        return left + mid + right
```
