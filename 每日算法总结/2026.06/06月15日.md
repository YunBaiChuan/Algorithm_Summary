## 第一题：删除链表的中间节点 https://leetcode.cn/problems/delete-the-middle-node-of-a-linked-list/?envType=daily-question&envId=2026-06-15

**思路：链表操作。首先快慢指针得到中点，接着特判一下是否只有一个节点，如果是的话，直接返回None即可；否则就遍历一下找中点的前一个节点，然后进行一次节点删除操作，最终返回即可**

**代码：**
```python
class Solution:
    def deleteMiddle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        slow = fast = head 
        while fast and fast.next:
            slow = slow.next 
            fast = fast.next.next 
        
        if slow == fast:
            return None
        
        p = head 
        while p.next and p.next != slow:
            p = p.next 
        
        p.next = slow.next 
        return head
```

## 第二题：小红开灯 https://www.nowcoder.com/practice/6e435ed7dd684f418c3b9bd6337ca417?channelPut=tracker2

**思路：思维 + 组合数学。我们可以按三种情况进行讨论：1.当n == k时，只能进行整体翻转，因此方案数为2；2.当k为奇数时，我们可以通过3次操作，使得只有一个元素翻转，因为本题可以对任意k个元素进行翻转，他不是连续的，那么方案数就是pow(2, n, mod)；3.当k为偶数时，每次只能翻转偶数个元素，那么总的方案数就是$C(n, 0) + C(n, 2) + C(n, 4) + ...$，根据二项式定理，取$a = b = 1$时有：$2^n = C(n, 0) + C(n, 1) + C(n, 2) + ... + C(n, n)$，那么只取偶数就是$2^{n - 1}$方案数，只取奇数同理也是$2^{n - 1}$方案数。最终，返回相应的答案即可**
