**思路：数学 + 枚举优化。首先用埃式筛预处理得到范围内的所有素数；接着观察式子$A + B = C^2$，第一个最简单的想法就是枚举< n的A, B, C，那么时间复杂度为O(n^3)，必然超时，考虑优化：1.枚举< n的C和B，那么A可以通过式子$A = C^2 - B$得到，此时复杂度为O(n^2)，依然会超时；2.继续观察式子，A和B最大为n，那么有$2 * n >= C^2$，因此$C <= isqrt(2 * n)$，那么枚举< isqrt(2 * n)的C和< n的B，就行，最终复杂度优化到$O(sqrt(n) * n)$，就可以通过了**

MAXN = 5 * 10 ** 5 + 5
prime = [False, False] + [True] * MAXN
for i in range(2, isqrt(MAXN) + 1):
    if prime[i]:
        for j in range(i * i, MAXN, i):
            prime[j] = False

res = list(i for i, x in enumerate(prime) if x)

def solve():
    n = II()
    mx_c = isqrt(2 * n)

    pc = bisect_right(res, mx_c)
    pb = bisect_right(res, n)

    ans = 0
    for i in range(pc):
        c2 = res[i] * res[i]
        for j in range(pb):
            a = c2 - res[j]
            if 2 <= a <= n and prime[a]:
                ans += 1

    print(ans)

t = 1
# t = II()
for _ in range(t):
    solve()
