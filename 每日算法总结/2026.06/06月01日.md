## 第一题：打折购买糖果的最小开销 https://leetcode.cn/problems/minimum-cost-of-buying-candies-with-discount/description/?envType=daily-question&envId=2026-06-01

**思路：排序贪心，逆向思维。从大到小排完序之后，遍历一遍算最大免费糖果的花费，那么最少花费就是总花费-免费糖果花费**

**代码：**
```python
class Solution:
    def minimumCost(self, cost: List[int]) -> int:
        cost.sort(reverse=True)
        res = 0 
        for i in range(2, len(cost), 3):
            res += cost[i]
        return sum(cost) - res
```

## 第二题：旺仔哥哥走迷宫 https://www.nowcoder.com/practice/4b4ee516c23d4bd2b838646363b5c395?channelPut=tracker2

**思路：思维 + bfs。由题意可知，如果连接了一条边的两个点中，只要有一个是陷阱，那么这条边就废了。因此，我们建图之前额外判断一下，最后跑一个bfs，看能否从1到达n即可**
