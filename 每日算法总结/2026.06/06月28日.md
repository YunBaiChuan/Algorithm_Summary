## 第一题：减小和重新排列数组后的最大元素 https://leetcode.cn/problems/maximum-element-after-decreasing-and-rearranging/description/?envType=daily-question&envId=2026-06-28

**思路：思维 + 贪心。首先对arr进行从小到大排序，然后再模拟一遍即可。注意当x < target时不能直接break，因为它后面还有可能增加，比如说1 1 3 3这种情况，最终结果可以是1 1 2 3；并且x < target并不是非法的，这个x仍满足题目绝对值差<= 1的条件**

**代码：**
```python
class Solution:
    def maximumElementAfterDecrementingAndRearranging(self, arr: List[int]) -> int:
        arr.sort()
        ans, target = 0, 1 
        for x in arr:
            if x >= target:
                ans += 1
                target += 1
        return ans 
```

## 第二题：跳跳跳 https://www.nowcoder.com/practice/53ecd7f5fb3942a58a0d769e5433029c?channelPut=tracker2

**思路：区间dp。这题不能用简单的贪心策略来做，而是应该在2 * a上跑一个区间dp，然后算环形数组中的最大值，即为答案**

def solve():
    n = II()
    a = LII()

    b = a * 2

    dp = [[0] * (2 * n) for _ in range(2 * n)]

    for i in range(2 * n):
        dp[i][i] = b[i]

    for length in range(2, n + 1):

            r = l + length - 1
