## 第一题：根据描述创建二叉树 https://leetcode.cn/problems/create-binary-tree-from-descriptions/description/?envType=daily-question&envId=2026-06-07

**思路：思维 + hash表。首先我们要对x，y进行树节点的创建，但由于不知道x，y是否已经被创建过了，因此要用hash表进行记录，将节点值作为建，创建的树节点为值，再结合is_left遍历一遍，就能建出来了。那根节点该怎么找？有两种方式：1.用一个名为childs的hash表，记录孩子节点，然后遍历nodes的时候检查是否为孩子；2.用一个root变量，然后通过异或来找，简单来说就是先把所有节点值异或起来，接着再把所有孩子的节点值异或起来，最终只有根节点的值会保留下来**

**代码：**
```python
class Solution:
    def createBinaryTree(self, descriptions: List[List[int]]) -> Optional[TreeNode]:
        nodes = {}
        root = 0 

        for x, y, is_left in descriptions:
            if x not in nodes:
                nodes[x] = TreeNode(x)
                root ^= x 
            if y not in nodes:
                nodes[y] = TreeNode(y)
                root ^= y 
            if is_left:
                nodes[x].left = nodes[y]
            else:
                nodes[x].right = nodes[y]
            root ^= y 
        
        return nodes[root]
```

**思路：思维 + 排序贪心。要使得序列的相邻差绝对值最大，那就可以先把数组从小到大排序，然后用一个双指针，每个大值指针j，匹配两个小值指针i（i和i + 1）。当i < j时才进行操作，最终不要忘了首尾还要额外加上，其实就是遍历完之后的a[i] - a[0]这部分**
