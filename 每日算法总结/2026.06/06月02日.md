## 第一题：最早完成陆地和水上游乐设施的时间 https://leetcode.cn/problems/earliest-finish-time-for-land-and-water-rides-i/description/?envType=daily-question&envId=2026-06-02

**思路：思维 + 贪心。首先要分类讨论两种情况：1.先完成陆地再完成海洋；2.先完成海洋再完成陆地；其次可以注意到这两种情况是类似的，那就可以写一个函数进行封装。具体来说就是找前者的最早完成时间 + 后者活动开启中的最快完成时间，然后取其中的min就是答案了**

**代码：**
```python
class Solution:
    def solve(self, landStartTime: List[int], landDuration: List[int], waterStartTime: List[int], waterDuration: List[int]) -> int:
        min_finish = min(start + duration for start, duration in zip(landStartTime, landDuration))
        return min(max(start, min_finish) + duration for start, duration in zip(waterStartTime, waterDuration))

    def earliestFinishTime(self, landStartTime: List[int], landDuration: List[int], waterStartTime: List[int], waterDuration: List[int]) -> int:
        land_water = self.solve(landStartTime, landDuration, waterStartTime, waterDuration)
        water_land = self.solve(waterStartTime, waterDuration, landStartTime, landDuration)
        return min(land_water, water_land)
```

## 第二题：小红的平行四边形 https://www.nowcoder.com/practice/917247383d1f4ff18e58586285f7a8c7?channelPut=tracker2

**思路：数学。首先要知道平行四边形有一个性质为对角线中点相同；其次要知道平行四边形的向量化计算公式，也就是两条对角线向量的叉积再除2。简单进行一下推导：$S = |a| * |b| * sinx = (\vec{a} \times \vec{b})\ /\ 2$，然后$\vec{a} \times \vec{b} = x1 * y2 - x2 * y1$。有这两个结论之后，我们就可以先进行中点分组，然后再根据面积公式计算出面积，然后不断取max即可。**

**注意：最后输出答案时要/2，但如果直接/2的话，对于大整数来说，python会有很大的浮点数误差。因此，我们需要对结果进行奇偶性区分，然后直接//2，再根据奇偶来补小数部分**

**代码：**

    return input()

    return int(input())

    return map(int, input().split())

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y

def solve():
    n = II()
    pts = []
    for _ in range(n):
        x, y = MII()
        pts.append((x, y))

    groups = defaultdict(list)
    for i in range(n):
        for j in range(i + 1, n):
            mx = pts[i][0] + pts[j][0]
            my = pts[i][1] + pts[j][1]
            dx = pts[j][0] - pts[i][0]
            dy = pts[j][1] - pts[i][1]
            groups[(mx, my)].append((dx, dy))

    ans = 0
    for key, vec_list in groups.items():
        m = len(vec_list)
        if m < 2:
            continue

        seen = set()
        uniq = []
        for v in vec_list:
            if v not in seen:
                seen.add(v)
                uniq.append(v)

        k = len(uniq)
        for i in range(k):
            for j in range(i + 1, k):
                cross = abs(uniq[i][0] * uniq[j][1] - uniq[i][1] * uniq[j][0])
                ans = fmax(ans, cross)

    if ans == 0:
        print(-1)
    else:
        if ans % 2 == 0: # 减少精度干扰
            print(f"{ans // 2}.0")
        else:
            print(f"{ans // 2}.5")

t = 1

    solve()
