**思路：思维 + 构造。首先有个特判，如果说s末尾是'0'，必然不满足条件。因为我们构造的是一个完整的排列，因此末尾的时候已经完整了，必然为'1'才对。接着就是先构造一个1-n的完整排列，然后遍历s，如果发现s[i - 1]为'0'，那就交换排列的a[i - 1]和a[i]，这样就能满足当前位置及前面不构成排列，遇到'1'就正常遍历，因为我们初始构造已经满足条件了。最终遍历一遍，然后输出即可**

    return input()

def solve():
    n = II()
    s = I()

    if s[-1] != '1':
        print(-1)
