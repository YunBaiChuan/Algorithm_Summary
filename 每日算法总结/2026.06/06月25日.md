## 第一题：统计主要元素子数组数目 II https://leetcode.cn/problems/count-subarrays-with-majority-element-ii/description/

**思路：思维 + 枚举右维护左。首先题目只对target和非target元素感兴趣，因此我们可以把题目转化为target就是1，非target就是-1，那么此时问题就转化为找有多少个子区间，其元素和严格 > 0；那我们就可以枚举右端点，然后左边维护累加和的有序集合，收集答案的时候就用二分找左侧 >= 当前s的位置，其索引就是左侧s[i] < s[j]的元素个数，也就是当前j位置满足条件的子区间个数**

**注意：这里为什么要用SortedList有序表？其实就是为了优化O(n)的前缀和查找s[i] < s[j]的元素个数，因为我们前缀和是浮动的一个状态，每次变化为-1/1。那就可以把前缀和收集到有序表中，然后直接用二分查找即可**

**代码：**
```python
class Solution:
    def countMajoritySubarrays(self, nums: List[int], target: int) -> int:
        sl = SortedList([0])
        ans = s = 0
        for x in nums:
            s += 1 if x == target else -1
            ans += sl.bisect_left(s)
            sl.add(s)
        return ans
```
