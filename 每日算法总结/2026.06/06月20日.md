## 第一题：灵梦的字符串问题 https://www.nowcoder.com/practice/787c1de8325147309918aeaf5e72e634?channelPut=tracker2

**思路：贪心 + 分组循环。首先要得到最小字符串，我们可以想到一个简单的贪心：如果s[i] > s[i - 1]，那么此时将s[i - 1]进行一次操作，得到的字符串肯定会更小。但这个贪心是不完整的，对于多个连续的s[i] > 多个连续的s[i - 1]来说，我们就得加个s[i] == s[i - 1]的判断，但是加了之后会使一些字符额外添加，导致整个字符串变长，字典序变大，也不行。那该如何解决？用分组循环，我们将整个字符串进行分组循环分段，用段来看s[i] > s[i - 1]的情况，然后对于每一段来说，将a[i - 1]从小到大排序，选代价最小的进行操作。最终，遍历操作一遍之后，得到答案**

**代码：**

import sys
input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''

def solve():
    n, m = MII()
    s = I()
    a = LII()

    dup = [False] * n
    rem = m
    i = 0
    while i < n:
        j = i
        while j + 1 < n and s[j + 1] == s[i]:
            j += 1
        if j + 1 < n and s[i] < s[j + 1]:
            lst = [(a[k], k) for k in range(i, j + 1)]
            lst.sort()
            for c, idx in lst:
                if c <= rem:
                    dup[idx] = True
                    rem -= c
                else:
                    break
        i = j + 1

    ans = []
    for i, ch in enumerate(s):
        ans.append(ch)
        if dup[i]:
            ans.append(ch)

    print(''.join(ans))

tt = 1
# tt = II()
for _ in range(tt):
    solve()
