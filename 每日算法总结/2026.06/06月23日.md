## 第一题：括号匹配问题 https://www.nowcoder.com/practice/f0ac14281dcd46c9b60987383d48a265?channelPut=tracker2

**思路：思维 + 栈匹配 + 贡献法。首先题目定义的括号串权值为其子序列中的最大合法括号长度，其次观察数据范围可知，我们得用一个$O(n)$算法才行。考虑用栈进行括号匹配，但是他有什么用？单独看没用，如果再加上贡献法，就完全不同了。我们栈匹配的时候，每个匹配到的括号，以他为中心，左右两边包含他的贡献就是$2 * (j + 1) * (n - i)$，最终遍历一遍，累加得到答案，十分巧妙**

**代码：**

import sys

def solve():
    s = I()

    n = len(s)
    st = []
    ans = 0
    for i, c in enumerate(s):
        if c == '(':
            st.append(i)
        elif st:

            ans += 2 * (j + 1) * (n - i)
