## 第一题：子集中元素的最大数量 https://leetcode.cn/problems/find-the-maximum-number-of-elements-in-subset/description/?envType=daily-question&envId=2026-06-27

**思路：思维 + 暴力枚举。由于k是指数级别增长的，因此暴力枚举的代价很小。那首先需要特判一下全用1组成的情况，这里的ans初始化为$(cnt[1] - 1)\ |\ 1$很巧妙，当1为奇数时不变，当1为偶数时就正常少1；接着就暴力枚举统计到的x，找$x^2, x^4, x^k....$，并且不断更新答案即可。不过要注意res更新ans那里，需要判断一下最终的x是否在cnt中，这样才能覆盖$[16, 16]$，其实为1的这种情况，细节还是挺多的**

**代码：**
```python
class Solution:
    def maximumLength(self, nums: List[int]) -> int:
        cnt = Counter(nums)

        ans = (cnt[1] - 1) | 1
        del cnt[1]

        for x in cnt:
            res = 0
            while cnt.get(x, 0) >= 2:
                res += 2
                x *= x
            ans = max(ans, res + (1 if x in cnt else -1))

        return ans
```
