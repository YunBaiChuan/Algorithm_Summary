## 第一题：包含所有三种字符的子字符串数目 https://leetcode.cn/problems/number-of-substrings-containing-all-three-characters/description/?envType=daily-question&envId=2026-06-30

**思路：不定长滑动窗口。不定长滑动窗口，越长越合法板子题，太板子了，不再多说**

**代码：**
```python
class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        n = len(s)
        cnt = Counter()
        ans = l = 0 
        for r, x in enumerate(s):
            cnt[x] += 1 
            while cnt['a'] >= 1 and cnt['b'] >= 1 and cnt['c'] >= 1:
                cnt[s[l]] -= 1 
                if cnt[s[l]] == 0:
                    del cnt[s[l]]
                l += 1 
            ans += l 
        return ans 
```
