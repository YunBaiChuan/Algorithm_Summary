## 第一题：时钟指针的夹角 https://leetcode.cn/problems/angle-between-hands-of-a-clock/description/?envType=daily-question&envId=2026-06-18

**思路：思维 + 模拟。首先把每个指针对应的指向数值给算出来；接着就算两个指针之间的分钟数，由于题目要求取min，那就可以先算出一个，另一个就是720总分钟数去减，两者取min即可；最终度数就是360° / 720份，再*算出来的分钟数即可**

**代码：**
```python
class Solution:
    def angleClock(self, hour: int, minutes: int) -> float:
        m_node = minutes / 5 
        h_node = hour + (minutes / 60)
        diff = 60 * abs(m_node - h_node)
        diff = min(diff, 720 - diff)
        return 360 / 720 * diff
```

## 第二题：阿宁睡大觉 https://www.nowcoder.com/practice/7186aac3eea14fb3a9001f0ba8a491ca?channelPut=tracker2

**思路：思维 + 贪心。首先可以观察到答案分成两个部分：1.原Z连续串算出的答案；2.删除多个z之后，使得Z产生连接时，产生的答案；接着我们就可以先用一个分组循环，把每个分段给算出来，然后求出第一部分答案，并统计可以删除的z连续串；然后对z进行从小到大排序，贪心地删除，这样可以使得第二部分的答案尽量多；最终，将两部分答案加起来即可**

def solve():

    s = list(I())

    i = ct = 0

        if arr_z[i] <= k:
            k -= arr_z[i]
            ct += 1
        else:
            break
        i += 1
