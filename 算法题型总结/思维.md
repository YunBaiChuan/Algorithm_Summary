### 1.数组中的第K个最大元素 https://leetcode.cn/problems/kth-largest-element-in-an-array/description/

**思路1：直接排序然后算，简单直白，暴力至上。时间复杂度是$O(nlogn)$**

**思路2：用堆来算，对于第K个最小元素来说，需要用大根堆；对于第K个最大元素来说，需要用小根堆。为什么？拿第K个最大元素来说，我们每次要弹出最小元素，留下的就是K个最大元素，此时堆顶就是第K个最大元素；同理，第K个最小元素，我们每次要弹出最大元素，剩下的就是K个最小元素，此时堆顶就是第K个最小元素。时间复杂度是$O(nlogk)$**

**代码：**
```python
class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        h = []
        for x in nums:
            heappush(h, x)
            if len(h) > k:
                heappop(h)
        return h[0]
```

**思路3：用快排的思想来做，可以把它理解成快速选择算法。这里没用荷兰国旗优化，它空间复杂度是$O(n)$，如果用了荷兰国旗优化，那么原地三指针操作的空间复杂度就是$O(1)$。不过时间复杂度不变，都是$O(n)$，推荐下面的写法，看着很清楚，写起来也比较简单**

**代码：**
```python
class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        def quick_select(nums, k):
            pivot = random.choice(nums)
            big, equal, small = [], [], []
            for num in nums:
                if num > pivot:
                    big.append(num)
                elif num < pivot:
                    small.append(num)
                else:
                    equal.append(num)
            if k <= len(big):
                return quick_select(big, k)
            if k > len(big) + len(equal):
                return quick_select(small, k - len(big) - len(equal))
            return pivot
        return quick_select(nums, k)
```

### 2.小红的矩阵 https://www.nowcoder.com/practice/eec2ed5b48b04a1492209ba08593a830?channelPut=tracker2

**思路：考虑上面的三种思路的话，是不可行的，为什么？因为我们没有数据啊，此题给出的是如何生成数据，而不是给出直接的数据。如果说我们模拟去生成数据的话，时间复杂度是$O(m * n)$的，量级达到了惊人的$10^{10}$，所以我们不能去生成数据。应该考虑二分，这又是为什么？这个首先要想到计数排序，对于数字比较少的情况，我们可以统计每个数字，小于它的个数，统计完成之后，那么这个数字就该放在小于它的个数那里，索引从0开始的话。所以说，这题同理，我们先二分答案出来个值，他表示i * j，然后check函数里面就逐行计算小于等于i * j的格子数，最终求和。如果cnt >= k的话，说明我们可以缩小答案；反之，需要扩大答案。可以看到，他也是满足单调性的。最终，我们就可以在不需要生成数据的情况下，以$O(nlog(mn))$的时间复杂度解决此题了。**

**补充：二分答案并不要求值域范围是连续的，他只要求数据具有单调性，即使值域有很多空洞，但他们并不会影响结果的计算，只有那些存在的值，才会造成跳变，影响答案**

**代码：**

```python
import math

def I():

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

    return list(map(float, input().split()))


fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''
这题挺好啊，有点计数排序的味道了，相比于用堆来做，更快。为什么？
因为堆来做的话，这个矩阵的元素值你就不好处理，他对于已经确定的值来说好做
'''

def solve():
    n, m, k = LII()

    def check(mid):
        cnt = 0
        for i in range(1, n + 1): # 统计每一行中“乘积 <= mid”的格子数，并且累加得到整个矩阵的“乘积 <= mid”的格子数
            cnt += fmin(m, mid // i)
        return cnt >= k

    l, r = 1, n * m
    while l <= r:
        mid = (l + r) >> 1
        if check(mid):
            r = mid - 1
        else:
            l = mid + 1
    print(l)

# t = II()
for _ in range(t):
    solve()
```

**那本题其实更像是一种不均匀的分组问题，然后查当前音符是属于哪个组的，如果是均匀分组的话，我们其实就可以用类似于位图的处理方法，用divmod计算除数和余数，确定分组，那对于这种不均匀的分组，我们其实可以用前缀和 + 二分查找来做**

### 1.小苯最短路 https://www.nowcoder.com/practice/2130991f48ae48b588398ba5842c7ec0?channelPut=tracker2

**思路：思维。首先我们要知道1到其他点的最短路径是什么？由于题目说了是无向完全图，即每个点都能直达另一个点，所以说直达可能是最短路径。假设直达不是最短路径，说明真正的最短路径之间会经过一些点，那么经过这些点的权重就是(a ^ b) + (b ^ c) + (c ^ d)....根据异或的性质，直达最短路径的权重，即起点值^终点值能够写成(a ^ b) ^ (b ^ c) ^ (c ^ d)...由于同形式的异或和不会大于算术和，因此直达的权重更小，它就是最短路径**

**并且题目要求把1到其他所有点的最短路径异或值给异或起来，其实就是(1 ^ 1) ^ (1 ^ 2) ^ (1 ^ 3) ^ (1 ^ 4).....写成式子就是(n & 1) ^ reduce(xor, range(1, n + 1))，即n的奇偶性^1到n的异或和。但这样写会超时，本题的n很大，所以说可以把上面的式子打表出来找规律，发现只有4种情况，为n, 0, n + 1, 1，那就直接根据%4的余数来输出答案即可**

### 2.小美的数组操作 https://www.nowcoder.com/practice/b65be999590b4dd5881461a8e892d76e?channelPut=tracker2

**思路：思维题。base case比较容易想到：1.操作必须同时+1和-1，所以说整个数组和不变；2.要求最大化众数的个数，由于可以进行任意次操作，所以说令$s = sum(a)$，那么当$s\ \%\ n == 0$时，我们可以把数组a中的所有数都变成平均数，他也是众数。那么plus(+1)和sub(-1)操作操作相同，只需要算一个就行。**

**除去base case以外就不太容易想了，由于$s\ \%\ n\ != 0$，所以说会产生余数，导致数组a中的元素无法都变成平均数，那此时的最大众数有多少个？答案是n - 1个，我们可以选出一个数字来通过和他操作，以存放多余的值。那么这个数字应该怎么选？贪心的想，为了操作最小化，那就应该用最小值或者最大值来存放这些多余的值**

**接下来就需要分类讨论下了：1.去掉最大值，把剩下的n - 1个数字都变成一样的，也就是剩下数的平均数。但这里的平均数我们需要区分一下是上限还是下限，为什么？因为我们额外拿出了最大值，他其实充当了一个中介，多了数可以给他，少了数可以从他那里拿，所以说上限和下限都能算。具体计算过程就是cal函数写的，排除最大值索引，然后算其他n - 1个数变成上限/下限的plus(+1)和sub(-1)操作数，最终返回其中的最大值，就是我们实际的操作数。那这两个操作数的差值是什么，其实就是额外和最大值(中介)操作的次数**

**然后就是去掉最小值的情况，他和去掉最大值的情况同理，这里不再过多描述。最后，不断取fmin然后输出结果即可**

**代码：**
```python
import sys
from collections import Counter

input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def GMI():
    return map(lambda x: int(x) - 1, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''

'''

def solve():
    n = II()
    a = LII()

    s = sum(a)
    if s % n == 0:
        op = 0
        num = s // n
        for x in a:
            op += x - num if x > num else 0
        print(op)
        return

    cur_mx = max(v for v in Counter(a).values())
    if cur_mx == n - 1:
        print(0)
        return

    def cal(p, idx):
        plus = sub = 0
        for i, x in enumerate(a):
            if i == idx:
                continue
            if x < p:
                plus += p - x
            elif x > p:
                sub += x - p
        return fmax(plus, sub)

    m = M = 0
    for i, x in enumerate(a):
        if x > a[M]:
            M = i
        if x < a[m]:
            m = i

    ans = inf
    # 情况1：排除最大值，让其他n-1个数相等
    sum_without_M = s - a[M]
    base = sum_without_M // (n - 1)

    ans = fmin(ans, cal(base, M)) # 下限
    ans = fmin(ans, cal(base + 1, M)) # 上限

    # 情况2：排除最小值，让其他n-1个数相等
    sum_without_m = s - a[m]
    base = sum_without_m // (n - 1)

    ans = fmin(ans, cal(base, m)) # 下限
    ans = fmin(ans, cal(base + 1, m)) # 上限

    print(ans)

t = 1
# t = II()
for _ in range(t):
    solve()
```

### 3.小红的数组清空 https://www.nowcoder.com/practice/c0784de498ca4779b3dc2a75fddcf12b?channelPut=tracker2

**思路：思维题。由于每个数可能出现多次，所以说先用hash表统计一下，然后排序贪心地算可以免费删除的最大次数$sub$，具体流程如下：先定义一个$pre\_val$变量表示上一个元素是多少，初始化为-1，因为题目说了输入数据$a_i >= 1$，这样初始化能保证他不会和第一个数连续**

**再定义一个$pre\_cnt$变量表示上一个元素出现的次数，然后遍历hash表判断是否连续。如果连续的话，免费的删除次数就是$fmin(pre\_cnt,\ c)$，累加到$sub$中。然后更新$pre\_val$和$pre\_cnt$，这里需要注意一下，由于我们可以形成的连续链长度>= 2，所以说$pre\_cnt$应该更新为当前元素的出现次数c，他不仅可以被上一个元素作用，也可以作用于接下来的元素。如果碰到不连续的了，那么直接令$pre\_cnt = 0$表示不会产生免费删除次数**

**最后清空整个数组的最小操作代价就是n - sub，直接输出结果即可**

**代码：**
```python
import sys
from collections import Counter

input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def GMI():
    return map(lambda x: int(x) - 1, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''

'''

def solve():
    n = II()
    a = LII()

    cnt = Counter(a)
    sub = 0
    pre_val = -1
    pre_cnt = 0

    for val, c in sorted(cnt.items()):
        if val != pre_val + 1:
            pre_cnt = 0

        sub += fmin(pre_cnt, c)
        pre_val = val
        pre_cnt = c

    print(n - sub)

t = 1
# t = II()
for _ in range(t):
    solve()
```

### 5.加油站 https://leetcode.cn/problems/gas-station/description/

**思路：两种解法，一种是优化过的滑动窗口，一种是思维**

**代码：优化过的滑动窗口**
```python
class Solution:
    def canCompleteCircuit(self, gas: List[int], cost: List[int]) -> int:
        n = len(gas)
        tmp = [0] * n 
        for i in range(n):
            tmp[i] = gas[i] - cost[i]

        l = r = 0
        while r < 2 * n:
            s = 0
            while s + tmp[r % n] >= 0:
                if r - l + 1 == n:
                    return l 
                s += tmp[r % n]
                r += 1
            l = r + 1
            r = l

        return -1
```

### 6.游游的最小公倍数 https://www.nowcoder.com/practice/385c7aa397e54bb58f36286ab0d65156?channelPut=tracker2

**思路：思维题。首先直接算最大的lcm比较困难，我们用另一个转换式子：$lcm(a,\ b) = a\ /\ gcd(a,\ b) * b$，这个写法是防溢出的。因此我们要让$lcm$最大，就需要让$a * b$最大，$gcd(a,\ b)$最小**

**对于$a * b$最大这个要求来说，我们根据题目说的$a + b = n$条件，以及高中学过的基本不等式，即$a + b = n$的前提下，有$a + b >= 2 * \sqrt{a * b}$，转化式子得到$a * b <= n^2/4$，当且仅当$a = b = n / 2$时取得$a * b$的最大值**

**对于$gcd(a,\ b)$最小来说，他只可能是1，因此我们可以写个gcd函数来方便后面的验证，当然python也可以直接调用math.gcd，这里我习惯自己手写**

**所以说有了上面两个分析之后，我们就可以先把$n$一分为二，然后再判断$n\ //\ 2$与$n\ - n\ //\ 2$的$gcd$是否为1。如果两者的$gcd$为1，不用操作；如果不为1，那就不断a--和b++（这样能保证两者的和始终为n），直到两者的gcd为1时停止。最终，输出结果即可**

**代码：**

### 7.二进制手表 https://leetcode.cn/problems/binary-watch/description/?envType=daily-question&envId=2026-02-17

**思路：正向思考通过turnedOn去找数非常困难，考虑逆向思考。直接暴力枚举可能的h和m，之后再统计枚举的h和m是否满足其二进制1个数和为turnedOn即可**

**然后可以注意下f""格式化输出里面的:02d这个写法，他和:.2f比较相似，也就是把小数点改成了0表示位数不够用0填充，2的含义相同都表示整体位数固定为2，然后前面的d表示为整数，后者的f表示为浮点数**

**代码：**
```python
class Solution:
    def readBinaryWatch(self, turnedOn: int) -> List[str]:
        ans = []
        for h in range(12):
            for m in range(60):
                if h.bit_count() + m.bit_count() == turnedOn:
                    ans.append(f"{h}:{m:02d}")
        return ans 
```

### 8.计数二进制子串 https://leetcode.cn/problems/count-binary-substrings/description/?envType=daily-question&envId=2026-02-19

**思路：分组循环，然后发现答案就是相邻两个连续的不同字符，其长度中最小值的累加和**

**代码：**
```python
class Solution:
    def countBinarySubstrings(self, s: str) -> int:
        n = len(s)
        pre = cur = ans = 0 
        for i in range(n):
            cur += 1
            if i == n - 1 or s[i] != s[i + 1]:
                ans += min(pre, cur)
```

**思路：思维 + 暴力枚举。由于k是指数级别增长的，因此暴力枚举的代价很小。那首先需要特判一下全用1组成的情况，这里的ans初始化为$(cnt[1] - 1)\ |\ 1$很巧妙，当1为奇数时不变，当1为偶数时就正常少1；接着就暴力枚举统计到的x，找$x^2, x^4, x^k....$，并且不断更新答案即可。不过要注意res更新ans那里，需要判断一下最终的x是否在cnt中，这样才能覆盖$[16, 16]$，其实为1的这种情况，细节还是挺多的**

**代码：**
```python
class Solution:
    def maximumLength(self, nums: List[int]) -> int:
        cnt = Counter(nums)

        ans = (cnt[1] - 1) | 1
        del cnt[1]

        for x in cnt:
            res = 0
            while cnt.get(x, 0) >= 2:
                res += 2
                x *= x
            ans = max(ans, res + (1 if x in cnt else -1))

        return ans
```

### 2.种树 https://www.nowcoder.com/practice/9602d50d189b4fa69755ba7b2b6df4a8?channelPut=tracker2

**思路：贪心。为了保证根节点具有最大的生命值，我们可以用一个贪心策略：大剪刀能用$m = (cnt + 1)\ //\ 2$次，那么就在前m层使用大剪刀，后更深的层使用小剪刀即可。并且题目说了，每次修剪为左右孩子到根，这个顺序天然和后序遍历一致。因此，我们就可以递归算一遍后序遍历，以及对应节点的深度；之后，再用贪心策略求出最终的答案并输出即可**

**注意：递归这里python很有可能超时，推荐用模拟栈来写。模拟栈的后序遍历有两种写法：1.先序遍历改一下孩子的访问顺序，最后整体翻转；2.额外用state状态变量进行标记**

**代码：**
```python
import sys
input = lambda: sys.stdin.readline().strip()

import math
inf = 10 ** 18

def I():
    return input()

def II():
    return int(input())

def MII():
    return map(int, input().split())

def LI():
    return input().split()

def LII():
    return list(map(int, input().split()))

def LFI():
    return list(map(float, input().split()))

fmax = lambda x, y: x if x > y else y
fmin = lambda x, y: x if x < y else y
isqrt = lambda x: int(math.sqrt(x))

'''

'''

def solve():
    n = II()
    ls = [0] * (n + 1)
    rs = [0] * (n + 1)

    cnt = 0
    for u in range(1, n + 1):
        l, r = MII()
        ls[u], rs[u] = l, r
        if l != 0:
            cnt += 1

    a = [0] + LII()
    m = (cnt + 1) // 2

    depth = [0] * (n + 1) # 存放节点深度
    order = [] # 存放后序遍历
    stack = [(1, 0, 1)]  # (节点, 状态, 深度)

    while stack:
        u, state, d = stack.pop()
        if state == 0:
            depth[u] = d
            stack.append((u, 1, d))
            if ls[u] != 0:
                stack.append((rs[u], 0, d + 1)) # 由于栈是后进先出，所以先入右
                stack.append((ls[u], 0, d + 1)) # 后入左，后续处理时左先弹出
        else:
            order.append(u)

    # 题目的操作天然就是左右根，符合后序遍历
    for u in order:
        if ls[u] == 0:
            continue

        l, r = ls[u], rs[u]
        if depth[u] <= m: # 贪心，上m层用大剪刀
            a[u] = fmax(a[l], a[r])
        else: # 下面更深的层用小剪刀
            a[u] = fmin(a[l], a[r])

    print(a[1])

t = 1
# t = II()
for _ in range(t):
    solve()
```

**思路：大思路想到了，就是压缩数组。接着贪心排序，算每个高度下的最大子矩阵面积，然后不断取max，就可以得到最终答案了**

```python
    def largestSubmatrix(self, matrix: List[List[int]]) -> int:
        n = len(matrix[0])
        heights = [0] * n 
        ans = 0 

        for row in matrix:
            for j, x in enumerate(row):
                if x == 0:
                    heights[j] = 0

                    heights[j] += 1

            for i, h in enumerate(hs):
                ans = max(ans, (n - i) * h)
        return ans
```

```python
                return 1
```

**思路：很巧妙的$O(n)$做法，首先从前往后遍历一遍，找最右边的不满足位置，那么他更右边的位置必然满足排序；同理再从后往前遍历一遍，找最左边的不满足位置，那么他更左边的位置必然满足排序。最终，将两个位置中间的长度就是需要改变的长度**

```python
class Solution:
    def findUnsortedSubarray(self, nums: List[int]) -> int:
        n = len(nums)
        mx = -inf
        r = 0
        for i, x in enumerate(nums):
            if x >= mx:
                mx = x
            else:
                r = i 
        
        mn = inf 
        l = n
        for i in range(n - 1, -1, -1):
            if nums[i] <= mn:
                mn = nums[i]
            else:
                l = i
```

### 16.最大平均通过率 https://leetcode.cn/problems/maximum-average-pass-ratio/description/

**思路：大根堆 + 贪心。每次进来一个人的时候，算$diff = (x + 1)\ /\ (y + 1) - x\ /\ y$，最终把那个人给diff增量最大的，这就可以用到大根堆结构。然后，为了追求更高精度，可以把上面的diff化简，写成单独的分式：$diff = (y - x)\ /\ (y * (y + 1))$**

**代码：**
```python
class Solution:
    def maxAverageRatio(self, classes: List[List[int]], extraStudents: int) -> float:
        n = len(classes)
        h = []
        for x, y in classes:
            diff = (x + 1) / (y + 1) - x / y # (y - x) / (y * (y + 1)) 精度丢失更少
            h.append((-diff, x, y))
        heapify(h)

        for _ in range(extraStudents):
            _, x, y = heappop(h)
            x += 1; y += 1 # 先加再算diff
            diff = (x + 1) / (y + 1) - x / y # (y - x) / (y * (y + 1)) 精度丢失更少
            heappush(h, (-diff, x, y))
        
        return sum(x / y for _, x, y in h) / len(h)
```

**思路：贪心 + 分组循环。首先要得到最小字符串，我们可以想到一个简单的贪心：如果s[i] > s[i - 1]，那么此时将s[i - 1]进行一次操作，得到的字符串肯定会更小。但这个贪心是不完整的，对于多个连续的s[i] > 多个连续的s[i - 1]来说，我们就得加个s[i] == s[i - 1]的判断，但是加了之后会使一些字符额外添加，导致整个字符串变长，字典序变大，也不行。那该如何解决？用分组循环，我们将整个字符串进行分组循环分段，用段来看s[i] > s[i - 1]的情况，然后对于每一段来说，将a[i - 1]从小到大排序，选代价最小的进行操作。最终，遍历操作一遍之后，得到答案**

### 7.循环轮转矩阵 https://leetcode.cn/problems/cyclically-rotating-a-grid/description/?envType=daily-question&envId=2026-05-09

**思路：模拟。利用方向向量进行问题的简化，先枚举每一圈，进行该圈元素的收集；接着旋转收集到的一维数组元素；最后填回二维矩阵中**

**代码：**
```python
DIRS = (0, 1), (1, 0), (0, -1), (-1, 0)  # 右下左上

class Solution:
    def rotateGrid(self, grid: List[List[int]], k: int) -> List[List[int]]:
        m0, n0 = len(grid), len(grid[0])

        # 从外到内枚举圈
        for i in range(min(m0, n0) // 2):
            m, n = m0 - i * 2, n0 - i * 2  # 这一圈的行数和列数
            x, y = i, i  # 这一圈的左上角
            a = []
            for dx, dy in DIRS:
                for _ in range(n - 1):
                    a.append(grid[x][y])
                    x += dx
                    y += dy
                m, n = n, m  # 每发生一次旋转，行列进行交换

            shift = k % len(a)
            a = a[shift:] + a[:shift] # 收集并处理该圈元素

            j = 0 
            for dx, dy in DIRS:
                for _ in range(n - 1):
                    grid[x][y] = a[j] # 再转一遍，填写元素
                    j += 1
                    x += dx
                    y += dy
                m, n = n, m

        return grid
```

### 2.使数组相似的最少操作次数 https://leetcode.cn/problems/minimum-number-of-operations-to-make-arrays-similar/description/

**思路：题目描述的-2，其实对于每个数来说，-2不会改变其奇偶性，因此我们对两个数组分别进行奇偶排序，然后算对应的总转移操作数，然后//4就是答案了**

**代码：**
```python
class Solution:
    def makeSimilar(self, nums: List[int], target: List[int]) -> int:
        def func(a):
            a.sort()
            odd, even = [], []
            for x in a:
                if x & 1:
                    odd.append(x)
                else:
                    even.append(x)
            return odd, even 
        
        nums_odd, nums_even = func(nums)
        target_odd, target_even = func(target)

        res = 0 
        m, n = len(nums_odd), len(nums_even)
        for i in range(m):
            res += abs(nums_odd[i] - target_odd[i])
        for j in range(n):
            res += abs(nums_even[j] - target_even[j])
        return res // 4
```

```python
        a = []
        mod = grid[0][0] % x

        for row in grid:
            for v in row:
                if v % x != mod:
                    return -1
                a.append(v)
        
        a.sort()
        median = a[len(a) // 2]
        return sum(abs(v - median) // x for v in a)
```

```python
        m = len(nums)

            d[x].append(i)

        ans = [-1] * n 
        for i, x in enumerate(queries):
            num = nums[x]
            row = d[num]

            rn = len(row)

            if len(row) < 2:
                continue

            p = bisect_left(row, x)
            l, r = (p - 1 + rn) % rn, (p + 1) % rn
            pl, pr = row[l], row[r]
            if pl > x:
                res1 = min(pl - x, m - (pl - x))
            else:
                res1 = min(x - pl, m - (x - pl))
            if pr > x:
                res2 = min(pr - x, m - (pr - x))
            else:
                res2 = min(x - pr, m - (x - pr))

            ans[i] = min(res1, res2)
```

## 贡献法

### 1.子数组的最小值之和 https://leetcode.cn/problems/sum-of-subarray-minimums/description/

**思路：首先要想到贡献法，对于每个位置的数来说，假设他是最小值，那么以他为最小值的子数组范围就应该在他左边最近比它小的数的索引 ~ 他右边最近比它小的数索引之间。那提到这几个关键词，自然就可以想到用单调栈去算了。**

**不过这里要主要细节：如果两个左右都写严格小于，也就是>=弹出的话，会出问题。如果遇到重复值，他会有一个重复统计，比如例子：$arr=[1,2,4,2,3,1]$里面的这两个2，那该如何解决？我们可以单独修改其中的一个边界，变成一个是严格小于，一个不是严格小于，这样就解决了，很巧妙的一个思路**

**代码：**
```python
class Solution:
    def sumSubarrayMins(self, arr: List[int]) -> int:
        mod = 10 ** 9 + 7 

        n = len(arr)
        st = []
        left = [-1] * n 
        for i, x in enumerate(arr):
            while st and arr[st[-1]] >= x:
                st.pop()
            if st:
                left[i] = st[-1]
            st.append(i)
        
        st.clear()
        right = [n] * n 
        for i in range(n - 1, -1, -1):
            x = arr[i]
            while st and arr[st[-1]] > x:
                st.pop()
            if st:
                right[i] = st[-1]
            st.append(i)
        
        ans = 0 
        for i, (x, l, r) in enumerate(zip(arr, left, right)):
            ans = (ans + x * (i - l) * (r - i)) % mod 
        return ans 
```

### 4.统计全1子矩形（单调栈优化dp） https://leetcode.cn/problems/count-submatrices-with-all-ones/description/

**思路：单调栈，动态规划，数组压缩。这里动态规划的转移方程就是：1.当左边没有比枚举的右侧边界更小的高度，那么当前位置子矩形数量就是$dp[i] = x * (i + 1)$；2.当左边有比枚举的右侧边界更小的高度，那么当前位置子矩形数量就是$dp[i] = dp[l] + x * (i - l)$，每次算好了之后，不断累加ans，最后输出就是一个一维数组的全1子矩形数量**

**最终，用数组压缩方法求解以0~m - 1行为底的全1子矩形数量，累加起来就是最终答案。这里面的的递推可以好好记一下，挺巧妙的一个递推关系**

**代码：**
```python
class Solution:
    def numSubmat(self, mat: List[List[int]]) -> int:
        m, n = len(mat), len(mat[0])
        
        def solve(a):
            st = []
            left = [-1] * n 
            for i, x in enumerate(a):
                while st and a[st[-1]] >= x:
                    st.pop()
                if st:
                    left[i] = st[-1]
                st.append(i)

            ans = 0 
            dp = [0] * n 
            for i, x in enumerate(a):
                l = left[i]
                if l == -1:
                    dp[i] = x * (i + 1)
                else:
                    dp[i] = dp[l] + x * (i - l)
                ans += dp[i]
            return ans 
        
        tmp = [0] * n
        ans = 0 
        for i in range(m):
            for j in range(n):
                tmp[j] = 0 if mat[i][j] == 0 else tmp[j] + 1
            ans += solve(tmp)
        
        return ans 
```

## 摩尔投票

### 1.多数元素 https://leetcode.cn/problems/majority-element/

**思路：摩尔投票。简单来说就是每次抵消两个不同的元素，最终看有没有剩下的元素。如果没有剩下的元素，说明全部抵消完了，没有多数元素；否则就再遍历一遍，统计下候选元素个数，看他是不是满足条件**

**代码：**
```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        cand = vote = 0 
        for x in nums:
            if vote == 0:
                vote = 1
                cand = x 
            elif cand == x:
                vote += 1
            else:
                vote -= 1
        
        if vote == 0:
            return -1 
        
        cnt = 0 
        for x in nums:
            if x == cand:
                cnt += 1

        return cand if cnt > len(nums) // 2 else -1
```

### 2.合法分割的最小下标 https://leetcode.cn/problems/minimum-index-of-a-valid-split/description/

**思路：思维 + 摩尔投票。由水王数/众数的性质来说，要使得左右两边的众数相同，那么必然就是全局的众数，因此先算出全局的众数及其个数，然后再遍历一遍，判断当前分割点的左右两边，是否都是众数即可**

**代码：**

```python
        cand = vote = 0 
        for x in nums:
            if vote == 0:
                vote = 1
                cand = x 
            elif cand == x:
                vote += 1
            else:
                vote -= 1
        
        if vote == 0:
            return -1 
        
        cnt = 0 
        for x in nums:
            if x == cand:
                cnt += 1

        l, r = 0, cnt 
        for i, x in enumerate(nums):

                l += 1
                r -= 1
```

### 3.多数元素 II https://leetcode.cn/problems/majority-element-ii/description/

**思路：摩尔投票扩展。从找众数到找出现个数 > n // k的元素，其实就是在它上面的扩展。简单来说就是准备k - 1个候选，一旦不同元素个数> k - 1个，就把这k个互不相同的元素删掉，最终再判断一下剩下候选元素中，哪些满足出现个数 > n // k即可**

**代码：**
```python
class Solution:
    def majorityElement(self, nums: List[int]) -> List[int]:
        
        def majority(nums, k):
            k -= 1
            cands = [[0] * 2 for _ in range(k)]
            for x in nums:
                update(cands, k, x)
            ans = collect(cands, k)
            return list(ans)
        
        def update(cands, k, x):
            for i in range(k):
                if cands[i][0] == x and cands[i][1] > 0:
                    cands[i][1] += 1
                    return
            
            for i in range(k):
                if cands[i][1] == 0:
                    cands[i][0] = x 
                    cands[i][1] = 1
                    return 
            
            for i in range(k):
                if cands[i][1] > 0:
                    cands[i][1] -= 1
            
        def collect(cands, k):
            ans = set()
            for i in range(k):
                cur = cands[i][0]
                cnt = 0 
                for x in nums:
                    if x == cur:
                        cnt += 1
                if cnt > len(nums) // (k + 1):
                    ans.add(cur)
            return ans 
        
        return majority(nums, 3)
```
